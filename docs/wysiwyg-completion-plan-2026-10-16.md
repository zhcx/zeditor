# 所见即所得剩余功能完成计划

沿用既有编辑模式设计及用户「继续完成剩余事项」的授权，保留上一轮全部改动。

1. 表格方向键：单元格内正常移动，到边界才跨格；Shift/Ctrl/Alt 保留原生语义；表格外边界连接相邻正文。
2. 列表结构：Tab/Shift+Tab 操作光标所在项及其后代；首项不凭空缩进；多位数字编号正确决定子项缩进。
3. 复杂文本块：支持嵌套引用、引用中的列表和列表中的引用、多段落列表项的序列化及偏移映射；代码/HTML/表格等专用交互结构继续保护。
4. 行内标记：增加符合 CommonMark 边界的下划线强调，保留词内下划线；支持已排版文本中的不同种类格式嵌套。
5. 交互对接：按实际视觉行判断上下跨块；块级公式点击复用公式弹窗；校对高亮不改 DOM 和源码。
6. 验证：扩展自动浏览器回归、单元测试、类型检查、静态检查、构建；尝试桌面构建。真实系统输入法手动验收应与合成事件测试分开记录。

既有设计明确排除的多光标、图表源码直接编辑不作为缺陷；源码窗口和源码模式继续提供对应能力。每阶段先观察失败用例，再修复，最后独立审查并更新检查记录。

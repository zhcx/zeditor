# 键盘快捷键

应用菜单中的「快捷键说明」可随时查看内置速查。

## 文件

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+N` | 新建标签页 |
| `Ctrl+O` | 打开文件 |
| `Ctrl+S` | 保存 |
| `Ctrl+Shift+S` | 另存为 |

## 编辑

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Ctrl+X` / `Ctrl+C` / `Ctrl+V` | 剪切 / 复制 / 粘贴 |
| `Ctrl+Shift+V` | 粘贴为纯文本 |
| `Ctrl+A` | 全选 |
| `Ctrl+B` / `Ctrl+I` | 加粗 / 斜体 |
| `Ctrl+K` | 创建 / 编辑链接（剪贴板为 URL 时自动填入） |

## 插入

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+Shift+T` | 插入 3×3 表格 |
| `Ctrl+Shift+I` | 插入图片 |

## AI 与检查

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+J` | 打开 / 关闭 AI 指令面板 |
| `Ctrl+Alt+V` | 检查文档本地链接 |
| `F2` / `Shift+F2` | 在校对 / 链接检查结果间跳转 |
| `Tab` | AI 指令面板中切换作用范围 |

## 表格内

| 快捷键 | 作用 |
| --- | --- |
| `Tab` | 下一单元格（末格自动加行） |
| `Shift+Tab` | 上一单元格 |
| `Enter` | 当前行下方新增一行 |
| 方向键 | 在单元格间移动 |

## 智能 Tab 导航

光标落在标记间时，`Tab` 依次尝试跳出：闭合括号 / 引号 → 行内格式（`**` `__` `~~` `==` 等）→ 链接字段。详见[编辑与格式](/guide/editing#智能-tab-导航)。

## 斜杠命令菜单

| 按键 | 作用 |
| --- | --- |
| `/`（行首） | 打开命令菜单 |
| `↑` / `↓` | 选择命令 |
| `Enter` / `Tab` | 确认 |
| `Esc` | 关闭 |

## 界面

| 快捷键 | 作用 |
| --- | --- |
| `Esc` | 退出沉浸模式 / 演示模式 / 关闭弹窗与浮动工具栏 |
| `F11` | 切换全屏 |
| `Ctrl+滚轮` | 缩放 Mermaid / Markmap / 工作流画布 |

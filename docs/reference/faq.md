# 故障排除

常见问题的原因与解决方法。如未覆盖，请到 [GitHub Issues](https://github.com/zhcx/zeditor/issues) 反馈。

## 安装与更新

| 问题 | 原因 | 解决方法 |
| --- | --- | --- |
| Windows 安装时 SmartScreen 拦截 | 安装包尚未代码签名 | 「更多信息 → 仍要运行」；发布包有哈希校验 |
| 「检查更新」失败 | 网络 / GitHub 访问问题 | 前往 [Releases 页面](https://github.com/zhcx/zeditor/releases)手动下载，覆盖安装即可 |

## 文件与保存

| 问题 | 原因 | 解决方法 |
| --- | --- | --- |
| 插入本地图片提示「请先保存文档」 | 图片需复制到文档同级 `.assets` 目录 | 先 `Ctrl+S` 保存一次再插入 |
| 双击标签页把文档关了 | 双击标签 = 关闭（非重命名） | 未保存会弹确认框，内容不会丢失 |
| 时间线没有版本记录 | 版本按操作自动记录 | 时间线仅记录已保存文档的历史版本 |

## 编辑与预览

| 问题 | 原因 | 解决方法 |
| --- | --- | --- |
| `[^1]` 脚注、`==高亮==` 预览不渲染 | 预览暂未启用这两种渲染插件 | 属预期行为；编辑器内仍可插入与原位编辑 |
| 预览图片显示「无法读取图片」 | 相对路径下文件被移动 / 删除 | 运行 `Ctrl+Alt+V` 链接检查定位缺失引用 |
| 中文输入异常 | 输入法引擎兼容性 | `设置 → 编辑器 → 输入法引擎` 切换为「传统输入层」 |
| 链接检查提示「请先保存文档」 | 相对路径需要基于磁盘位置解析 | 先保存文档再检查 |

## 文档转换

| 问题 | 原因 | 解决方法 |
| --- | --- | --- |
| 提示 `converter_module_missing` | 未安装 AnyDoc 模块 | `设置 → 文档转换` 在线安装，或导入离线 ZIP |
| 下载转换模块失败 | 网络 / GitHub 访问问题 | 从 [converter-v1.3.0 Release](https://github.com/zhcx/zeditor/releases/tag/converter-v1.3.0) 下载离线包导入 |
| 健康检查失败 | 模块文件损坏 | 「重新安装」或重新导入模块 |
| 转换结果为空 | 源文件为扫描件 / 图片型 PDF | 确认源文件包含可提取文本；扫描型暂不支持 |

## AI 助手

| 问题 | 原因 | 解决方法 |
| --- | --- | --- |
| 对话报认证错误 | API Key 未填或失效 | `设置 → AI 助手` 检查密钥（可从环境变量导入） |
| 「获取模型列表」失败 | 端点 / 密钥不对，或网络问题 | 核对端点；自定义服务商需 OpenAI 兼容 |
| 思维链不显示 | 所选服务商不支持思维链 | 换用 DeepSeek / 硅基流动 / Kimi 等支持的模型 |
| 联网搜索不可用 | 未配置搜索服务 | `设置 → 网络搜索` 启用并填 Tavily Key 或 SearXNG 地址 |

## 本地 Agent

| 问题 | 原因 | 解决方法 |
| --- | --- | --- |
| 面板显示「Agent 尚未启用」 | 未开启开关 | `设置 → AI 助手 → 启用本地 Agent（Beta）` |
| 检测显示「不可用 / 不兼容」 | CLI 过旧 | 升级对应 CLI 到支持结构化流式输出的版本 |
| Agent 改动没出现在文件里 | Git 仓库中走 worktree 隔离 | 在面板的「待应用变更」中勾选并应用 |
| 每步都要审批 | 分级审批默认逐次确认 | 审批卡片选「本会话同类允许」，或临时切「完全访问」 |

## MCP 集成

| 问题 | 原因 | 解决方法 |
| --- | --- | --- |
| AI 助手连不上 Zeditor | 客户端未重启 | 配置安装后**完全退出并重启**该 AI 助手 |
| 状态显示「⚠ 路径不匹配」 | 客户端配置文件路径变化 | `设置 → 集成` 点「安装 / 修复」 |
| AI 提示 `INVALID_PATH` | 请求访问了工作区外的文件 | 属安全边界：先在 Zeditor 中打开对应文件夹 |
| AI 修改想跳过审阅 | 默认差异审阅 | 开「自动批准编辑」（仅完全信任时） |

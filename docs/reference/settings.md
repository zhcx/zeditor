# 设置参考

设置面板（菜单「功能 → 设置」）为左侧分类导航 + 右侧内容区，修改先暂存，点底部「**保存**」统一写入（语言与部分外观项即时生效）。共 11 个分类。

## 外观

| 设置项 | 选项 / 默认值 | 说明 |
| --- | --- | --- |
| 界面显示语言 | 简体中文 / 繁體中文 / 日本語 / 한국어 / English，默认跟随系统 | 更改即时生效 |
| 主题 | 12 套主题 +「跟随系统」，默认深色 | 界面、编辑器与图表整体换色 |
| 界面字体 / 内容字体 | 默认 Microsoft YaHei，可读取本机字体 | 分别作用于界面与编辑 / 预览 / 对话 |
| 字号 | 滑块，拖动实时预览 | 编辑器 / 预览 / AI 对话字号 |
| 行高 | 1.0–3.0，步进 0.1 | 内容行高 |

## 编辑器

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| 自动保存间隔 (ms) | 30000 | 不小于 1000 |
| 输入法引擎 | 原生 EditContext | 传统输入层为旧版 WebView 回退 |
| 启用拼写检查 | 关 | 标记拼写问题 |
| 启用自动补全 | 开 | 编辑补全建议 |
| 启用自动配对与 Tab 跳出 | 开 | 括号 / 引号 / Markdown 标记配对，代码区停用 |
| 固定显示编辑快捷栏 | 关 | 关闭时仅选中文本浮现 |
| 启用内联弹窗 | 开 | 点击链接 / 图片 / 公式 / 脚注原位编辑 |
| 检查本地链接 | 开 | AI 校对时自动并联链接检查 |
| 常用表情 | 8 个默认 emoji | Emoji 选择器顶部常用项，最多 24 个 |

## 图床

- **图床服务**：本地（默认）/ Cloudinary / PicGo / S3 / OSS；
- **Cloudinary**：云名称、API Key、API 密钥、上传文件夹；
- **PicGo**：服务器地址（默认 `http://127.0.0.1:36677`）；
- **S3 / OSS**：服务商（阿里云 OSS / AWS S3 / 腾讯云 COS / 华为云 OBS / MinIO / 自定义）、端点、桶、地域、密钥、自定义路径、HTTPS；
- **本地**：保存目录（默认 `./assets/images`）、命名规则（时间戳 / UUID / 原始名称）。

| --- | --- |

| HTML 模板 | 默认（另有极简 / 学术） |

## AI 助手

- **启用 AI 助手**（默认关）：总开关；
- **AI 服务商**：13 家（OpenAI / Anthropic / Gemini / DeepSeek / 硅基流动 / 小米 MiMo / 火山引擎 / LongCat / 智谱 / MiniMax / Kimi / Ollama / 自定义），每家独立密钥与端点；
- **API 密钥**：支持从环境变量导入；**模型**：可搜索下拉 + 获取模型列表；
- **温度**：默认 0.7；
- **自动伴写建议**（默认关）与建议延迟（默认 2000ms，500–10000）；
- **写作风格**：正式（默认）/ 活泼 / 学术 / 创意 / 自定义提示词；
- **启用本地 Agent（Beta）**（默认关）：默认 Agent（Claude Code / Codex / OpenCode / Pi）、各后端的可执行文件 / 模型覆盖 / Agent 或 Profile / 推理强度，以及「检测本机 Agent」；
- **AI 未配置时回退本地 AI Agent**（默认开）：关闭后 AI 未配置时直接报错，不再调用本机 CLI。引擎决策顺序为「强制 Agent > AI 助手 API > 本地 Agent 后备（总开关）」，校对与伴写一致；
- **每个 Agent 后端可单独启用 / 停用**（缺省启用）：停用后该后端从 Agent 面板下拉、默认 Agent 下拉与本地桥接候选中移除，配置区弱化置灰；旧配置兼容；
- **校对 / 伴写引擎**：可显式选择走 AI 助手 API 或本地 AI Agent，状态栏与面板文案标明当前引擎。

## 网络搜索

| 设置项 | 默认值 |
| --- | --- |
| 启用网络搜索 | 关 |
| 首选服务 | Tavily（或自建 SearXNG） |

- **Tavily**：API Key（`tvly-…`）、搜索深度（basic / fast / advanced / ultra-fast，默认 basic）、最大结果数（默认 5，1–20）、请求摘要答案（默认开）；
- **SearXNG**：API 地址（默认 `http://localhost:8080`）、可选 API Key、语言、分类、安全搜索、时间范围、最大结果数。

## 云同步

WebDAV 与 S3 两节独立配置（详见[云备份](/guide/cloud-backup)）：

- **WebDAV**：服务器地址、用户名、密码 / 应用密码、远端根目录（默认 `/Zeditor`）、「测试连接」、「浏览全部备份」；
- **S3**：端点、桶、地域、Access Key / Secret Key、Path-Style 开关、远端根目录；同样保留最近 20 个内容版本（SHA-256 去重）。

# Zeditor 清晰舒适界面优化

日期：2026-10-04。用户选择的方向：保留现有风格，改善层次、留白和操作便利。

## 设计与实现

延续现有桌面编辑器布局和 12 套主题，以主题变量控制配色。提高工作台小字号与点击区域的可读性，弱化重复装饰，让当前文档、选中项目和保存状态更容易辨认。正文继续使用用户配置的字体、字号；调整标题间距、引用、表格和代码块的排版细节。

- 标题栏的当前文档区域变为切换入口。点击或按 Ctrl/Cmd+P，可按名称和路径搜索已打开的文档，方向键选择、Enter 打开、Esc 关闭；焦点留在弹窗内，关闭后回到原操作位置。新组件按需加载。
- 标签栏支持左/右方向键、Home、End，切换后让当前标签滚动到可见区域，悬停显示完整名称或路径。
- 工具栏改为按实际文字宽度测量，不再以固定 34px 推算；空间不足的操作收纳到“更多”，全部命令仍可使用。字体变化和窗口缩放会重新测量，隐藏测量轨不创建额外交互控件。
- 活动栏提供格式工具栏的显示/隐藏按钮，复用已有偏好保存流程。
- 预览上方的对齐区增加“实时预览”和“专注阅读”入口。
- 未保存状态同时通过文字和小圆点表达；长路径有悬停提示，窄窗口优先保留操作和统计信息。
- 空白编辑区域提供写作提示及常用快捷键，第一笔输入后自动收起，不拦截编辑器点击。
- 设置导航与弹窗按钮保持统一尺寸，菜单、标签、表单保留可见焦点样式。

## 验证

单元测试覆盖文档搜索、多关键词匹配、标签键盘导航、工具栏宽度边界。浏览器验证覆盖文档切换、焦点与 Esc、工具栏显隐和窄窗口布局，以及所有主题。原有编辑、撤销、预览、保存和性能回归继续运行。

```powershell
npm test
npm run lint
npm run build
node scripts/verify-editor-ui.mjs
node scripts/verify-editor-performance.mjs
```

浏览器脚本需要运行在 127.0.0.1:1425 的开发服务器和已安装的 agent-browser，使用独立无头会话。

本轮验证环境为 Windows + Edge。包含后续改进的 430 项前端测试、代码检查和生产构建通过；12 套主题、1440/1100/960/900 像素窗口下的布局通过浏览器验证。包括文档搜索与切换、弹窗焦点、Esc、标签导航、工具栏显隐、空白提示、保存状态，以及关闭按钮的键盘保存保护。字号、字间距、编码与最终图标见[补充记录](encoding-typography-icons-2026-10-04.md)。

固定和选中文字后出现的浮动工具栏均检查宽度与命令可用性。文档搜索还覆盖输入法组合事件：确认键、方向键在组合阶段不会提前切换文档。

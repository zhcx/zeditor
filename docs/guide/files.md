# 文件与工作区

## 打开与保存

| 操作 | 方式 |
| --- | --- |
| 新建 | `Ctrl+N`、标签栏 `+`、双击标签栏空白处 |
| 打开文件 | `Ctrl+O`（可多选，可直选可转换文档） |
| 拖拽打开 | 把文件 / 文件夹拖进窗口 |
| 保存 | `Ctrl+S`（未命名文档转「另存为」） |
| 另存为 | `Ctrl+Shift+S`；未命名且已启用 AI 时会先建议文件名 |
| 自动保存 | 默认每 30 秒自动保存已有路径的修改，`设置 → 编辑器` 可调 |

### 选择文件编码

支持 UTF-8、UTF-8 BOM、UTF-16 LE/BE（含与不含 BOM）、GBK、GB18030、Big5、Shift-JIS、Windows-1252。无法自动识别旧文件时应用会询问；打开后若文字显示不正确，可点击状态栏的编码名称重新读取。选择保存编码只影响后续写入，不兼容的字符会被拒绝写入。

macOS 界面将快捷键显示为 ⌘（Command）、⇧（Shift）、⌥（Option）；Windows 和 Linux 显示 Ctrl、Shift、Alt。

Windows 安装版关联 `.md` / `.markdown` 后，资源管理器会显示专属 Markdown 图标。桌面版图标来自 `src-tauri/icons/markdown-file.png`，由构建脚本生成 ICO 后随安装程序注册。

::: tip 未保存保护
有未保存修改的标签会显示 `●` 标记；关闭时弹窗让你选择「保存 / 不保存 / 取消」，不会静默丢失内容。
:::

## 资源管理器

侧边栏「资源管理器」自上而下五个分组（均可折叠）：

### 打开的编辑器

列出所有标签页，未保存的显示圆点，点 `×` 直接关闭。

### 工作区

- 支持**多根工作区**：打开文件夹时可一次多选，也可反复点「打开文件夹」追加；
- 每个根目录可单独「关闭文件夹」（只移出工作区，不删磁盘内容）；
- 重启应用自动恢复上次的工作区；工具栏提供「展开 / 折叠所有文件夹」。

### 大纲

按当前文档 `#` ~ `######` 标题自动生成，点击跳到编辑器对应行；文档首次出现标题时自动展开。

### 近期记录

最近打开的文件与文件夹（最多 50 条，按 `设置 → 资源管理器 → 历史记录保留天数` 过滤，默认 30 天）。点击文件打开，点击文件夹加入工作区。

### 时间线：本地版本历史

当前文档的自动版本记录，无需 Git：

- 点击任一版本打开「历史版本」对话框，含**版本预览**与**与当前对比**（逐行 diff）两个页签；
- 行内快捷按钮：对比 `≠`、恢复此版本 `↶`、删除记录 `×`；
- 恢复前可先看 diff，确认无误再动手。

## 文件树操作

- 点击文件夹展开 / 折叠（子目录懒加载），点击文件打开；
- **点击 PDF / DOCX 等可转换文档会直接触发转换为 Markdown**；
- 文件树自动轮询刷新（默认 5 秒，可在设置关闭）；
- 当前打开文件所在目录会自动加入工作区。

### 右键菜单

| 目标 | 可用操作 |
| --- | --- |
| 文件 | 打开、新建文件夹（同级）、复制、剪切、复制路径、在资源管理器中打开、重命名、删除 |
| 文件夹 | 展开 / 折叠、新建文件、新建文件夹、复制、剪切、**粘贴**、复制路径、在资源管理器中打开、重命名、刷新、删除 |
| 工作区根 | 以上全部 +「关闭文件夹 / 关闭所有文件夹」 |

删除带确认对话框，删除文件会联动关闭相关标签页；新建与重命名为内联输入框（`Enter` 确认、`Esc` 取消）。

## 搜索与替换

**当前文档查找替换**：活动栏切到「搜索」视图，仅作用于**正在编辑的正文**——输入即出命中列表（行号 + 整行文本），支持上一个 / 下一个、`替换`、`全部替换`（带确认）、区分大小写与正则（`$1` 分组引用）。未保存的修改同样可搜；替换保留撤销历史，一次 `Ctrl+Z` 可回退。

**跨文件搜索**：标题栏搜索框或 `Ctrl+P` 打开顶部统一搜索栏。

**空输入时**先展示两个「开箱即用」分组：

| 分组 | 内容 | 说明 |
| --- | --- | --- |
| 快捷命令 | 新建文件、搜索当前文档、检查链接、AI 指令面板、演示模式、分屏 / 沉浸阅读 / 沉浸写作、导出为 HTML / Word、设置 | 与「文件 / 功能」菜单同源同词，右侧显示快捷键；空输入只列**前 5 条**，末尾「更多命令…」（或直接输入 `>`）进入命令模式，可按名称筛选全部命令 |
| 近期文件 | 最近打开过的文件 | 与侧边栏「近期记录」共用同一份数据 |

**输入关键词后**结果分四组：

| 分组 | 数据来源 | 说明 |
| --- | --- | --- |
| 已打开的文档 | 标签页标题 / 路径 | 切换文档 |
| 文档内容 | 标签页内存正文 | 含未保存修改，**即时出结果** |
| 工作区文件 | 文件清单缓存 | 按文件名 / 路径匹配，**即时出结果** |
| 工作区内容 | 工作区文件内容 | 受 1500 文件 / 2 秒预算约束，超出提示「结果已截断」 |

`↑` / `↓` 选择、`Enter` 打开、`Esc` 关闭。「高级选项」可设置区分大小写、正则、文件类型筛选与忽略目录；默认忽略 `.git`、`node_modules`、`target`、`dist`、`.idea`、`.vscode`。

## 链接检查

`Ctrl+Alt+V` 或「功能 → 检查链接」可检查文档中本地链接 / 图片 / 媒体引用是否指向真实存在的文件，详见[链接检查](/guide/link-check)。

# 导出

所有导出入口在菜单 `文件 → 导出` 子菜单（编辑器右键菜单也提供 PDF / Word / HTML 快捷导出）。

## 导出模板

导出前可选用 9 套排版预设，并可逐项微调：

| 预设 | 适用 |
| --- | --- |
| 公众号文章 | 微信公众号排版 |
| 学术论文 | 标题自动编号、学术排版 |
| 公文排版 | 党政机关公文样式 |
| 技术文档 | README / 使用手册 |
| 演示长图 / 小红书长图 | 社交媒体分享图 |
| A4 打印 | 通用打印版式 |
| GitHub README | GitHub 风格 |
| 自定义 CSS | 完全自定义样式 |

可调项：字体、行距、水印、包含目录（H1–H3）、包含封面、页眉页脚、标题自动编号、自定义 CSS。选择会自动记住。Word 使用原生文档样式，支持字体、行距、页边距、封面、目录、页眉页脚和标题编号；自定义 CSS 不应用到 Word，水印保留为页眉文字。

## 图表与工作流

预览里的二次增强也会进入导出管线，不再只导出 ` ```mermaid ` 这类源码：

| 内容 | HTML / PDF | 长图 / 公众号 | Word |
| --- | --- | --- | --- |
| Mermaid 图表 | 内联 SVG | PNG 图片 | PNG 图片 |
| Markmap 思维导图 | 内联 SVG | PNG 图片 | PNG 图片 |
| ` ```svg ` 图形 | 内联 SVG（净化后） | PNG 图片 | PNG 图片 |
| GitHub Actions 工作流（`yaml` 围栏） | 内联 SVG 依赖图 | PNG 图片 | PNG 图片 |

- 长图跟随当前明暗主题；HTML / PDF / Word / 公众号的页面是浅色，图表固定使用浅色（Word 为白底 PNG）。工作流图受“设置 → 工作流 → 在预览中渲染”开关控制，关闭时保持 YAML 源码。
- 某一个图表无法解析或渲染失败时，该处保留源码，并在保存后弹出说明；其余内容继续导出。
- Markmap 与工作流会先离屏排版再取图，长文档里的图表较多时，导出会比纯文本稍慢。
- 公众号编辑器若丢弃内联图片，请改用“保存 HTML”，或先导出图表图片再手动插入。

## 导出为 HTML

直接执行：应用当前模板生成单个 HTML 文件，弹出系统保存对话框。

## 导出为 PDF

打开导出对话框，除模板外还可设置页面：

- **页面格式**：A4 / A3 / Letter / Legal
- **方向**：纵向 / 横向
- **页边距**：5–50mm（默认 20mm）
- **页眉页脚**：可开关

导出过程分五步显示进度（初始化 → 加载 → 渲染 → 生成 → 完成）。

## 导出为 Word

保存为真正的 OOXML `.docx` 文件，包含可继续编辑的文字、标题样式、粗体、斜体、删除线、代码、列表、表格、外部超链接和原生脚注。图片写入文档内部，移动文件后仍可离线查看；不是将 HTML 改名为 Word 文件。

- 使用 A4 页面，应用当前模板的字体、行距和页边距。
- 模板启用封面时插入独立封面和分页；启用目录时生成 H1–H3 的原生目录域。打开文件后，Office/WPS 可能要求更新目录，请选择更新整个目录。
- 启用页眉页脚时包含标题和动态页码；页数由 Office/WPS 排版计算。
- 本地图片必须使用相对路径，并位于已保存文档的目录或其子目录（例如 `.assets`）。百分号编码的中文和空格路径可正常读取，忽略 URL 的查询串和片段。目录外路径、绝对路径和指向目录外的符号链接会被拒绝；可先把图片复制到 `.assets` 后再导出。
- 支持 PNG、JPEG、GIF、BMP；WebP、SVG、AVIF 经浏览器解码后转成 PNG。每张图片最大 20 MiB，最多 4000 万像素。远程 HTTP/HTTPS 图片仅在网络和服务器跨域设置允许时下载内嵌，超时为 15 秒。任何图片无法读取或转换时，导出会显示原因并停止，避免生成缺图的交付文件。

以下内容有明确的格式降级，保存后会弹出说明：

| 内容 | Word 中的结果 |
| --- | --- |
| 数学公式 | 保留可编辑的 TeX 原文，尚不生成原生 Word 公式 |
| Mermaid、Markmap、SVG 围栏、工作流图 | 渲染为内嵌 PNG；渲染失败时保留语言标记与源码 |
| 原始 HTML、播放器等交互组件 | 保留可读文字，不转换 HTML 布局和交互行为 |
| 本地链接和文内锚点 | 保留文字和目标地址；按需在 Word 中重新设置跳转 |
| Wiki 链接 | 保留显示文字，不提供笔记库跳转 |
| 音视频和平台播放器语法 | 保留标题或来源链接，不嵌入可播放的媒体文件 |
| 任务列表 | 保留勾选状态字符，不生成交互式表单控件 |
| 脚注中的表格 | 保留表格原始文字 |

已通过 ZIP 校验和 OOXML 部件解析验证正文、样式、表格、图片关系、脚注引用、目录域及页码域。2026-10-20 在本机 WPS 12.1 实际打开导出的复杂样稿：3 页、5 张内嵌图片、1 个脚注，标题与正文可编辑，无修复提示；字体替换、目录更新和跨版本显示仍需目视检查。

## 导出为图片

生成 PNG 长图，提供 5 种画布比例，2 倍分辨率渲染，跟随当前主题底色，带实时预览：

| 比例 | 适用 |
| --- | --- |
| 1:1 | 社交媒体卡片 |
| 4:3 | 演示文稿、平板 |
| 16:9 | 宽屏、视频封面 |
| 9:16 | 手机长图、故事 |
| A4 | 打印、文档截图 |

图表会先转成 PNG 数据地址再进入画布，避免 Markmap 的嵌套 `foreignObject` 在光栅化时丢失；含 `img`、`br` 等标签的正文会先序列化为良构 XHTML，否则整张长图可能无法解码。

## 导出公众号排版 HTML

专为微信公众号设计：

- 6 个原创主题：翡翠指南 / 朱砂论述 / 石墨刊读 / 留白随笔 / 琥珀便签 / 橄榄书页；
- 全内联样式（677px 版心、微软雅黑），粘贴到公众号编辑器不丢样式；
- 自动添加封面卡（标题 + 站点标识）；
- 图表固定用浅色主题转成内联 PNG；若公众号编辑器丢弃图片，请改用「保存 HTML」或单独插入图表图片；
- 两种动作：「**复制富文本**」直接粘贴进公众号后台，或「保存 HTML」。

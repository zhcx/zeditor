# 导出

所有导出入口在菜单 `文件 → 导出` 子菜单（编辑器右键菜单也提供 PDF / Word / HTML 快捷导出）。

## 导出模板（各方式共用）

导出前可选用 9 套排版预设，并可逐项微调：

| 预设 | 适用 |
| --- | --- |
| 公众号文章 | 微信公众号排版 |
| 学术论文 | 标题自动编号、学术排版 |
| 公文排版 | 党政机关公文样式 |
| 技术文档 | README / 使用手册 |
| 演示长图 / 小红书长图 | 社交媒体分享图 |
| A4 打印 | 通用打印版式 |
| GitHub README | GitHub 风格 |
| 自定义 CSS | 完全自定义样式 |

可调项：字体、行距、水印、包含目录（H1–H3）、包含封面、页眉页脚、标题自动编号、自定义 CSS。选择会自动记住。

## 导出为 HTML

直接执行：应用当前模板生成单个 HTML 文件，弹出系统保存对话框。

## 导出为 PDF

打开导出对话框，除模板外还可设置页面：

- **页面格式**：A4 / A3 / Letter / Legal
- **方向**：纵向 / 横向
- **页边距**：5–50mm（默认 20mm）
- **页眉页脚**：可开关

导出过程分五步显示进度（初始化 → 加载 → 渲染 → 生成 → 完成）。

## 导出为 Word

直接执行，保存为 `.doc` 文件，可用 Office / WPS 继续编辑。

## 导出为图片

生成 PNG 长图，提供 5 种画布比例，2 倍分辨率渲染，跟随当前主题底色，带实时预览：

| 比例 | 适用 |
| --- | --- |
| 1:1 | 社交媒体卡片 |
| 4:3 | 演示文稿、平板 |
| 16:9 | 宽屏、视频封面 |
| 9:16 | 手机长图、故事 |
| A4 | 打印、文档截图 |

## 导出公众号排版 HTML

专为微信公众号设计：

- 6 个原创主题：翡翠指南 / 朱砂论述 / 石墨刊读 / 留白随笔 / 琥珀便签 / 橄榄书页；
- 全内联样式（677px 版心、微软雅黑），粘贴到公众号编辑器不丢样式；
- 自动添加封面卡（标题 + 站点标识）；
- 两种动作：「**复制富文本**」直接粘贴进公众号后台，或「保存 HTML」。

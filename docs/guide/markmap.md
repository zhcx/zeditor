# Markmap 思维导图

Markmap 让你**用普通 Markdown 标题层级画思维导图**：`#` 是中心主题，`##` 是分支，`###` 是要点，不需要学习任何新语法。

## 基本用法

````markdown
```markmap
# 产品发布
## 市场准备
### 官网改版
### 媒体预热
## 发布日
### 线上直播
### 社群答疑
```
````

预览会把这段标题渲染成可交互的 SVG 导图树。

## 插入模板

三个入口都会插入带「中心主题 / 分支一 / 分支二」的模板并选中中心主题，直接改字即可：

- 斜杠命令 `/markmap`；
- 工具栏「图表 → Markmap 思维导图」；
- 菜单「功能 → 插入思维导图」。

## 交互操作

| 操作 | 方式 |
| --- | --- |
| 平移 | 鼠标拖动 |
| 缩放 | `Ctrl` + 滚轮（普通滚轮仍用于滚动文档） |
| 折叠 / 展开分支 | 点击节点旁的圆圈 |
| 复位视角 | 点击「适应视图」按钮 |

## 导出 PNG

点击导图下方的「导出 PNG」按钮，以 **2 倍分辨率**导出当前视图；桌面端弹出系统保存对话框（文件名取自文档名）。导图配色跟随当前主题（8 色分支色板）。

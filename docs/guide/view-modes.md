# 视图模式与演示

## 四种工作区模式

入口：菜单「功能」、活动栏的编辑模式弹层、状态栏左侧的模式标签，或快捷键 `Ctrl+Alt+M`（当前模式带 ✓）。

| 模式 | 布局 | 适合 |
| --- | --- | --- |
| 源码对照 | 编辑器 + 预览左右分屏 | 熟悉 Markdown 语法，边写边看（此前的「分屏模式」） |
| 所见即所得 | 整篇按最终排版渲染，直接在渲染结果上编辑 | 不熟悉 Markdown 语法，像写文档一样写作 |
| 沉浸阅读 | 隐藏编辑器，只显示预览 + 可折叠大纲 | 通读、校对成稿 |
| 沉浸写作 | 隐藏预览与侧栏，只显示编辑器 + 可折叠大纲 | 专注写作 |

### 首次启动选择

首次安装（设置文件里还没有编辑方式）时会弹出「选择你的编辑方式」：选「所选即所得」会直接进入文档式编辑，选「源码对照」保持左右分屏。选择会被记住，之后启动直接进入该模式；随时可在状态栏、活动栏或菜单里切换。

- 沉浸模式下的大纲栏可折叠成「纲」字竖条；点击大纲项在阅读模式中平滑滚动预览，在写作模式中跳到编辑器对应行；
- 沉浸条上的「对话」按钮可在沉浸模式下开关 AI 侧栏；
- **退出沉浸模式：按 `Esc`**，回到你选择的持久模式（源码对照或所见即所得）。

::: tip 配合全屏
`F11` 进入系统全屏后再切沉浸模式，是干扰最少的写作环境。
:::

## 演示模式

把 Markdown 文档变成全屏幻灯片（基于 Reveal.js），入口：菜单「功能 → 演示模式」。

### 分隔规则

- 顶层 `---` 分隔幻灯片（代码围栏内的 `---` 不会误切）；
- 文档开头的 YAML frontmatter 会自动剥离，不影响分页；
- 没有可演示内容时会提示「使用 --- 分隔幻灯片后再试」。

```markdown
# 第一页
开场内容

---

# 第二页
下一张幻灯片
```

### 放映与退出

- 渲染与预览一致：公式、Mermaid、任务列表、代码高亮全部可用；
- 导航：方向键 / 屏幕翻页控件 / 进度条；版面 1280×720；
- **退出：`Esc`** 或左上角「✕ 退出」。

# 数学公式

Zeditor 内置 KaTeX 渲染引擎，支持行内与块级数学公式，预览即所得。

## 四种写法

```markdown
行内公式：$E = mc^2$

块级公式（独立成行）：
$$
\int_{-\infty}^{\infty} e^{-x^2} \, dx = \sqrt{\pi}
$$

块级公式（LaTeX 原生写法）：
\[ a^2 + b^2 = c^2 \]

行内公式（LaTeX 原生写法）：\( a + b \)
```

- `$…$`：行内公式，与文字同排
- `$$…$$`：块级公式，独占一行居中显示
- `\[…\]` 与 `\(…\)`：兼容 LaTeX 原生分隔符

## 行为细节

- **代码不受影响**：代码块与行内代码中的 `$` 不会被误渲染为公式；
- **渲染失败回退**：语法错误时显示原始文本，不会整页崩溃；
- **安全渲染**：KaTeX 以严格模式运行，不执行嵌入 HTML。

## 编辑辅助

- 工具栏「公式」按钮可插入行内公式或公式块模板；
- 斜杠命令 `/math`、`/mathblock` 快速插入；
- 编辑器中**点击公式**会弹出原位编辑窗，带 KaTeX 实时预览，随光标自动开合。

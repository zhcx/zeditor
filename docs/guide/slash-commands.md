# 斜杠命令

在编辑器**行首**输入 `/`，即可呼出命令菜单，快速插入各种 Markdown 结构——不用背语法，像聊天一样打字。

## 基本用法

1. 把光标放在空行（或行首），输入 `/`；
2. 继续输入文字筛选命令，例如 `/tab` 筛出表格相关命令；
3. `↑` / `↓` 选择，`Enter` 或 `Tab` 确认，`Esc` 关闭菜单。

::: tip
斜杠命令只在 `/` 是行首第一个有效字符时触发，正文中间输入 `/` 不会误弹菜单。
:::

## 全部命令

### 标题与文本

| 命令 | 作用 |
| --- | --- |
| `/h1` ~ `/h4` | 插入一至四级标题 |
| `/bold` | 加粗 `**…**` |
| `/italic` | 斜体 `*…*` |
| `/strike` | 删除线 `~~…~~` |
| `/highlight` | 高亮 `==…==` |
| `/inlinecode` | 行内代码 |
| `/quote` | 引用块 |
| `/comment` | HTML 注释（预览中不可见） |

### 列表与块

| 命令 | 作用 |
| --- | --- |
| `/ul` | 无序列表 |
| `/ol` | 有序列表 |
| `/todo` | 任务列表 `- [ ]` |
| `/code` | 代码块 |
| `/table` | 插入 3×3 表格 |
| `/hr` | 分割线 |
| `/details` | 可折叠内容 `<details>` |
| `/toc` | 目录 `[TOC]` |
| `/slide` | 幻灯片分隔符 `---`（配合[演示模式](/guide/view-modes#演示模式)） |

### 链接与媒体

| 命令 | 作用 |
| --- | --- |
| `/link` | 链接 |
| `/image` | 图片（本地 / 链接 / 图床） |
| `/video` | 视频嵌入 |
| `/audio` | 音频嵌入 |
| `/emoji` | 表情选择器 |

### 公式与脚注

| 命令 | 作用 |
| --- | --- |
| `/math` | 行内公式 `$…$` |
| `/mathblock` | 公式块 `$$…$$` |
| `/footnote` | 脚注 `[^1]` |

### 图表

| 命令 | 作用 |
| --- | --- |
| `/mermaid` | Mermaid 流程图模板 |
| `/sequence` | 时序图模板 |
| `/gantt` | 甘特图模板 |
| `/state` | 状态图模板 |
| `/class` | 类图模板 |
| `/markmap` | Markmap 思维导图模板 |

### AI 命令

需要先在设置中[启用 AI 助手](/guide/ai/)。结果会以「AI 修改建议」差异审阅的方式呈现，确认后才写入文档。

| 命令 | 作用 |
| --- | --- |
| `/ask` | 就当前位置向 AI 提问（先弹输入框补充问题） |
| `/ai` | 从当前位置续写 |
| `/write` | 按要求写作（先弹输入框补充要求） |
| `/polish` | 润色 |
| `/translate` | 翻译（中英互译） |
| `/summarize` | 总结 |

# 工作流查看器

Zeditor 可以把 **GitHub Actions 工作流 YAML** 渲染为可交互的 job 依赖图（DAG），并提供结构化编辑与诊断能力。全程本地解析，不联网执行。

## 两种出现方式

1. **内联渲染（只读）**：Markdown 中 ```` ```yaml ```` 围栏的内容「长得像」GitHub Actions 工作流时，预览中自动替换为依赖图。
2. **独立编辑器（可写回）**：直接打开 `.github/workflows/*.yml` 或内容可识别的工作流文件时，预览区整体变为「依赖图 + 结构化编辑器」分屏，修改可以写回编辑器。

::: tip 关闭内联渲染
不希望 Markdown 中的 YAML 被渲染成图？在 `设置 → 工作流` 中关闭「在预览中渲染工作流图」。
:::

## 画布交互

| 操作 | 方式 |
| --- | --- |
| 缩放 | `Ctrl` + 滚轮，或底部 `− / +` 控件 |
| 平移 | 拖动滚动条 |
| 查看 job 详情 | 点击 job 节点 |
| 重置缩放 | 底部「重置」 |

图例会标出**错误**、**警告**与**回边**（循环依赖或自依赖）。

## 诊断（GHA-*）

解析时本地生成诊断：重复 job、循环依赖、未知引用、`pull_request_target` 安全提示等。错误与警告以计数徽章显示，**点击诊断可跳转到源码对应行**（内联图中自动换算行偏移）。

## 结构化编辑与写回

在独立编辑器模式下：

- 修改 job / step / `with` 字段，变更以补丁队列列出，每条可单独撤销；
- 头部显示待保存变更数，「保存」写回编辑器（再按 `Ctrl+S` 落盘），「放弃修改」清空队列；
- 「保存时保留 YAML 格式」开启时（默认），注释、锚点与缩进原样保留；关闭则输出规范化 YAML（会丢注释）。

## 导出

| 按钮 | 作用 |
| --- | --- |
| 复制 Mermaid | 生成可直接贴进 README 的 Mermaid 流程图代码 |
| 复制 SVG | 复制矢量图到剪贴板 |
| 导出 SVG | 保存为 `.svg` 文件（桌面端弹保存对话框） |

无法解析出 jobs 时，自动降级为诊断列表展示。

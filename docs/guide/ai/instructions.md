# AI 指令面板

AI 指令面板是**面向选区与文档的文本处理中心**：润色、翻译、摘要、大纲、校对一键完成，也支持自定义指令。入口：`Ctrl+J` 或菜单「功能 → AI 指令面板」。

## 作用范围

执行任何指令前先选范围，`Tab` 在三档之间切换：

| 范围 | 说明 |
| --- | --- |
| 选中文本 | 只处理选中内容；无选区时自动降级为光标所在段落 |
| 光标所在段落 | 当前段落整体 |
| 整个文档 | 全文处理 |

## 内置指令

| 指令 | 作用 | 结果写回方式 |
| --- | --- | --- |
| 润色 | 提升表达质量 | 替换目标文本（差异审阅） |
| 精简 | 压缩篇幅、去冗余 | 替换（差异审阅） |
| 简化 | 降低复杂度、更好懂 | 替换（差异审阅） |
| 改写 | 换一种说法 | 替换（差异审阅） |
| 扩展 | 充实内容 | 替换（差异审阅） |
| 生动化 | 更有画面感（创意风格） | 替换（差异审阅） |
| 摘要 | 生成全文摘要 | 插入到文档 |
| 大纲 | 提取文档大纲 | 插入到文档 |
| 翻译 | 中英互译 | 替换（差异审阅） |
| 校对 | 找出错别字、语法、标点问题 | 在校对面板中逐项查看应用 |

::: tip AI 修改建议
凡「替换」类操作都不会直接落盘：结果先以**差异审阅**弹窗展示（原文 vs 修改），确认后才写入，随时可拒绝。
:::

## 自由指令

面板底部输入框可发送任何自定义要求（如「把这段改成项目符号列表」），带历史记录，回退可重用。

## 自定义指令（Genies）

把常用指令写成 Markdown 文件放进 **`genies` 文件夹**，即成为面板中的一键指令：

- 面板内提供「打开 genies 文件夹」按钮，放入文件后重载即可；
- 文件内容即提示词，文件名即指令名；
- 适合沉淀团队统一的改稿规范、固定翻译腔调等。

## 编辑器内的 AI 入口

同一套能力也分布在写作路径上：

- **斜杠命令**：`/ask` `/ai` `/write` `/polish` `/translate` `/summarize`（见[斜杠命令](/guide/slash-commands#ai-命令)）；
- **右键菜单**：「AI 润色」「AI 翻译」直接作用于选区；
- **AI 对话面板**：自由问答与上下文对话（见 [AI 助手](/guide/ai/)）。

## 校对与链接检查

「校对」指令的结果在专用面板呈现，可逐项应用；同时会自动并联**本地链接检查**（M001 / M002 缺失链接条目），详见[链接检查](/guide/link-check)。

# 本地 Agent（Beta）

本地 Agent 让你在本机的 **Claude Code / Codex / OpenCode / Pi** CLI 直接处理当前工作区：修文档、改代码、跑命令，全程在 AI 面板中完成。Zeditor **复用各 CLI 自己的登录与默认模型，不保存其账号凭据**。

## 启用步骤

1. 本机安装并登录任一 CLI（`claude` / `codex` / `opencode` / `pi`）；
2. 在 Zeditor 中打开目标工作区目录；
3. `设置 → AI 助手 → 启用本地 Agent（Beta）`，选择默认 Agent；
4. 点「**检测本机 Agent**」验证各 CLI 的版本与兼容性（过旧的 CLI 会标记为不可用，而不是带病启动）；
5. AI 面板顶部切换到「Agent」标签。

### 每个 Agent 可单独配置

| 配置项 | 说明 |
| --- | --- |
| 可执行文件 | 留空则从 PATH 查找 |
| 模型覆盖 | 留空使用 CLI 默认模型 |
| Agent / Profile | Claude Code 显示 Agent，Codex 显示 Profile（Pi 无此概念，自动隐藏） |
| 推理强度 | 自动 / 低 / 中 / 高 / 超高（Claude Code 额外有「最大」） |

::: tip 会话恢复
每个后端维护独立的会话列表，标题由 CLI 从首条提问生成；切换后端会自动接续该后端的会话。
:::

## 上下文

- **自动引用**当前编辑文档；
- 「@ 引用」按钮：引用当前选区或整篇文档；
- 「+」按钮：添加工作区内其他文件作为附加上下文。

## 审批机制

输入工具栏可切换两种审批模式：

### 分级审批（默认）

| 操作类型 | 处理 |
| --- | --- |
| 隔离区内读取、worktree 内文件编辑 | 自动放行 |
| Shell 命令、联网、MCP 工具 | 逐次审批 |
| 外部路径写入、`git push` | 硬性禁止 |

审批卡片提供四档：**拒绝 / 本次允许 / 本会话同类允许 / 本会话完全允许**。

### 完全访问

切换时弹确认框，本次会话不再询问。该模式**仅存于内存**，重启、新建或恢复会话后自动回到分级审批。

## 隔离变更审阅（Git worktree）

这是本地 Agent 最重要的安全设计：

- 在 **Git 仓库**中，每个新会话都会创建独立的**临时 Git worktree**，Agent 的所有修改先落在隔离区，不碰你的工作区；
- 回合结束后对比基线，产出「**待应用变更**」列表（每文件状态、增删行数）；
- **勾选后按文件应用**；应用前会检查文件是否被你手动改过，有冲突即中止，不会覆盖；
- 「丢弃会话」删除 worktree 与本地事件历史；
- 在**非 Git 目录**中，授权后修改会直接写入（界面有明确横幅提示）。

::: warning Pi 后端的差异
Pi 不提供逐工具审批，安全边界依赖隔离 worktree 与「应用前审阅」；其扩展弹出的选择 / 确认提示仍以统一审批卡片呈现。
:::

## 时间线

Agent 的工作过程以时间线展示，活动块折叠收纳：思考过程、终端命令与输出、文件修改、网页搜索、MCP 工具调用等；助手消息可一键「插入编辑器」。

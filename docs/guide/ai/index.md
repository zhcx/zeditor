# AI 助手

Zeditor 内置 AI 助手：侧边栏自由对话、写作指令、伴写建议与智能校对，支持 13 家服务商（含本地 Ollama），全部请求直连你选择的服务商。

## 启用与配置

1. 打开 `设置 → AI 助手`，开启「**启用 AI 助手**」；
2. 选择**服务商**并填写 **API 密钥**（可点 `⤓` 从系统环境变量导入）；
3. 点「**获取模型列表**」拉取可用模型并选择，或手动填写模型名；
4. 按需调整温度（默认 0.7）与写作风格。

## AI 对话面板

点击活动栏 AI 图标打开面板，顶部可在「**AI 对话**」与「**Agent**」之间切换（见[本地 Agent](/guide/ai/agent)）。

### 基本对话

- `Enter` 发送、`Shift+Enter` 换行，流式输出，随时「停止生成」；
- 输入框可拖拽顶边调高；
- 「新建对话」与「对话历史」管理多个会话；服务商 / 模型偏好**按工作区分别记忆**。

### 上下文

| 能力 | 说明 |
| --- | --- |
| 关联文档 | 自动把当前编辑文档作为对话上下文，气泡栏显示文档名，可随时取消 |
| 附件上传 | 回形针按钮：图片（png/jpg/gif/webp/bmp/svg）与文本文件（txt/md/json/yaml/xml/csv/log） |
| 工作区上下文 | 输入区上方折叠条：添加工作区文件作为检索来源，支持按标题选章节、敏感文件排除规则、「仅检索片段不上传全文」，并显示本轮将发送的 Token 数 |

### 思考模式

工具栏可选择思考强度：**关闭 / 快速 / 均衡（默认）/ 深度**。DeepSeek、硅基流动等支持思维链的服务商会在「正在思考…」折叠块中实时流式展示推理过程，正文开始后自动收起。

### 联网搜索

先在 `设置 → 网络搜索` 中启用并配置（Tavily 或自建 SearXNG），然后在对话工具栏打开搜索按钮：发送前自动联网检索，回答下方显示可展开的**来源卡片**（来源编号、域名、时间），支持一键「导出来源」为 Markdown 脚注。

### 消息操作

- 「**插入编辑器**」：把回复插入到光标处（自动处理段落衔接）；
- 「复制」：复制回复内容；底部「清空对话」重置当前会话。

## 智能校对

- 「使用 AI 校对」开启时，校对调用 AI 检测错别字、语法与标点问题；
- 关闭后改用**内置 Markdown 静态校对**：未闭合代码围栏、反向链接、跳级标题、断开的锚点、表格列数不匹配等正确性检查；
- 校对结果在专用面板中逐项查看、按 `F2` / `Shift+F2` 跳转；
- 校对时会**自动并联本地链接检查**（见[链接检查](/guide/link-check)）。

## 伴写建议

开启「自动伴写建议」（默认关）后，写作停顿超过设定延迟（默认 2000ms，可调 500–10000ms）会在光标处弹出 AI 续写建议，可采纳或忽略。

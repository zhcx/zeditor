# 链接检查

文档里的本地链接、图片和媒体引用会随文件移动、改名而失效。Zeditor 内置**本地链接检查**，一键找出文档中所有「指向不存在文件」的引用。

## 触发方式

- 菜单「功能 → **检查链接**」；
- 快捷键 **`Ctrl+Alt+V`**；
- 执行 AI「校对」时会**自动并联**运行链接检查（受设置开关控制）。

::: warning 需要先保存
链接检查基于文档在磁盘上的真实路径解析相对路径，**未保存的文档无法检查**，会提示「请先保存文档」。
:::

## 检查范围

| 目标类型 | 示例 | 说明 |
| --- | --- | --- |
| 链接 | `[说明](./other.md)` | 相对路径、绝对路径、根相对路径 |
| 图片 | `![图](.assets/cover.png)` | 含 `{width=…}` 尺寸语法 |
| 媒体指令 | `@[video](demo.mp4)` | 视频 / 音频嵌入 |
| 引用定义 | `[ref]: ./path` | Markdown 引用式链接 |

**不会误报**的情况：外部 URL（`https://…`）、纯锚点（`#标题`）、UNC 网络路径（`\\server\share`）、代码块与行内代码中的内容。

## 查看结果

检查结果出现在**校对面板**中，与其他校对项一起按文档位置排序：

- **M001**：图片 / 媒体文件不存在
- **M002**：链接 / 引用目标不存在

使用 **`F2` / `Shift+F2`** 在结果之间循环跳转，编辑器自动定位到对应位置；修复后再次检查即可确认清零。

## 设置

`设置 → 编辑器 → 检查本地链接`（默认开启）控制校对时是否自动并联链接检查；显式按 `Ctrl+Alt+V` 或走菜单总是执行，不受该开关影响。

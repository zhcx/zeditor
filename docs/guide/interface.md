# 界面总览

## 主要区域

```text
┌────────────────────────────────────────────────┐
│ 菜单栏：Zeditor ｜ 文件 ｜ 功能                   │
├───┬─────────┬──────────────┬───────────────────┤
│ 活 │ 侧边栏   │ 标签栏        │                   │
│ 动 │ 资源管理器├──────────────┤                   │
│ 栏 │ / 搜索   │ 编辑器 ｜ 预览 │  （可分屏）        │
├───┴─────────┴──────────────┴───────────────────┤
│ 状态栏：保存 ｜ 上传 ｜ 云同步 ｜ 编码 ｜ MCP         │
└────────────────────────────────────────────────┘
```

- **活动栏**（最左竖条）：切换侧边栏的「资源管理器 / 搜索」视图、切换明暗主题、进入沉浸模式。
- **侧边栏**：资源管理器含「打开的编辑器 / 工作区 / 大纲 / 近期记录 / 时间线」五个可折叠分组（见[文件与工作区](/guide/files)）。
- **标签栏**：多标签管理，`+` 或双击空白处新建。
- **工具栏**：位于编辑器上方，格式 / 编辑 / 插入三组文字按钮，空间不足时收进「•••」菜单。
- **编辑器与预览**：默认左右分屏，可拖动分隔条调整宽度；两侧基于标题锚点双向同步滚动，点击预览段落会跳到编辑器对应行。
- **状态栏**：显示保存与上传状态、云同步进度、MCP 桥接状态，以及当前文档的文字编码；点击编码名称可选择保存编码或用其他编码重新读取。

## 菜单栏

菜单栏共三个菜单，编辑与视图类功能统一收在「功能」中：

### Zeditor（应用菜单）

| 菜单项 | 作用 |
| --- | --- |
| 快捷键说明 | 内置快捷键速查弹窗 |
| Markdown 语法 | Markdown 语法入门与速查 |
| 检查更新 | 检测并安装新版本（见[自动更新](#保持更新)） |
| 关于 Zeditor | 功能列表、技术栈与版本信息 |

### 文件

| 菜单项 | 快捷键 | 作用 |
| --- | --- | --- |
| 新建 | `Ctrl+N` | 新建标签页 |
| 打开 | `Ctrl+O` | 打开文件（支持多选与可转换文档） |
| 导入并转换文档… | — | 将 Office / PDF 等转换为 Markdown |
| 最近的文件夹 | — | 最近打开的文件夹（最多 10 条） |
| 保存 / 另存为 | `Ctrl+S` / `Ctrl+Shift+S` | 保存文档 |
| 导出 ▸ | — | HTML / PDF / Word / 公众号排版 / 图片 |

| 菜单项 | 快捷键 | 作用 |

## 主题

内置 **12 套主题**（6 浅色 + 6 深色），界面、编辑器语法高亮、图表与导图配色整体联动。切换入口：

- 菜单「功能 → 主题」，当前主题带 ✓；
- `设置 → 外观 → 主题` 下拉框（含「跟随系统」选项，随系统明暗自动切换）；
- 活动栏的明暗切换按钮：在浅色与深色的默认主题之间快速对切。

| 浅色主题 | 深色主题 |
| --- | --- |
| 浅色（Light） | 深色（Dark） |
| 雅致（Elegant） | 暖木（Gruvbox） |
| 简白（Notion） | 午夜（Midnight） |
| 作家（Writer） | 夜航（Solarized Dark） |
| 熊红（Bear） | 极地（Nord） |
| 羊皮纸（Sepia） | 德古拉（Dracula） |

::: tip 全屏
`F11` 可在窗口与全屏之间切换，配合沉浸模式效果更佳。
:::

## 保持更新

应用菜单 →「检查更新」：自动对比 GitHub 最新版本，展示更新说明，一键下载安装（Windows 下安装前请保存文档，应用会自动退出并启动安装程序）。检查失败时可直接前往 [Releases 页面](https://github.com/zhcx/zeditor/releases)。

# 编辑与格式

Zeditor 的源码编辑器基于 Monaco（VS Code 同款内核），同时提供直接编辑排版结果的所见即所得模式。

## 所见即所得编辑

在「所见即所得」模式下，整篇文档按最终排版渲染，你直接在渲染结果上编辑，看不到 `#`、`**`、`[]()` 这些标记（入口见[视图模式](/guide/view-modes)）。

新建或清空文档时，编辑区会显示「从一个想法开始」的引导，并提示 `/` 插入内容、`Ctrl P` 切换文档；开始输入后引导自动收起。该提示垂直居中于编辑表面，与源码编辑、阅读预览的提示保持同一水平线，切换模式时位置不跳动。

**可以就地编辑的块**

| 块类型 | 操作 |
| --- | --- |
| 段落 / 标题（h1–h6）/ 引用 | 直接输入；`Ctrl+1`–`Ctrl+6` 设标题级别，`Ctrl+0` 还原段落 |
| 无序 / 有序 / 任务列表（含嵌套与多段落项） | 回车续项；`Tab` / `Shift+Tab` 调整当前项及其子项，首项不凭空缩进；点击复选框切换完成状态 |
| 粗体 / 斜体 / 删除线 / 行内代码 / 链接 | 选中文字后使用浮动快捷栏，或 `Ctrl+B` / `Ctrl+I`；`Ctrl+K` 创建或编辑链接 |
| 表格 | 点击单元格输入文字，表格工具栏增删行列与设置对齐；`Tab` 切换单元格，`Enter` 增行；方向键到达文字/视觉行边界后跨格 |
| 围栏代码块 | 点击代码或「编辑代码」进入编辑，代码即时保存；用顶部下拉框切换语言，「完成编辑」恢复高亮 |

**Markdown 快捷输入**（行首输入即刻转块）：`# ` 至 `###### `、`- ` / `* ` / `+ `、`1. `、`> `、```` ``` ````、`---`。粘贴同样按 Markdown 处理：浏览器复制的富文本会转成 Markdown，复制图片会落到文档的 `.assets` 目录。选中部分文字后粘贴会在选区原位替换，保留选区两侧未选中文字及其格式，不会残留原来的 `**`、`~~` 或反引号。

**行内标记输入即渲染**：支持 `**粗体**` / `__粗体__`、`*斜体*` / `_斜体_`、`***粗斜体***` / `___粗斜体___`、`~~删除线~~`、`` `代码` ``。闭合时转换为对应格式；内容为空、前后带空白或标记未真正闭合时不转换。下划线按 Markdown 边界判定，`文件_name_` 这样的词内写法仍保留为文字。已有粗体或斜体中可以输入另一种格式。

**快捷指令**：在段落开头输入 `/`，复用原有可搜索命令菜单；用方向键选择、回车插入，也可点击命令。

**回车与退格**：回车在块内拆行（列表续项、引用内新建段落），在末尾空列表项或空引用段落上再按回车会退出一层；引用中的列表退出后仍留在引用里。支持嵌套引用、多段落列表以及列表和引用相互嵌套。退格在块首删空块、去前缀或与上一段合并；`Delete` 在块尾向后合并下一段落。表格、代码块、分隔线不参与跨块合并。

**方向键**：`←` / `→` 在正文块首尾跨块；`↑` / `↓` 按实际视觉行判断边界，折行后的首末行也能离块，并尽量保留水平位置。表格中在单元格边界跨格，表格外边界连接相邻正文；正文跨块仍会越过代码、表格和分隔线。`Shift` / `Alt` / `Ctrl` 组合键保留原生选择和按词移动。

**块级操作**：悬停块左侧的手柄并点击，可上移、下移、复制、删除块，在下方插入段落，或就地编辑该块源码（面板占用块自身的位置，`Ctrl+Enter` 保存、`Esc` 取消，前后文保持可见）；没有其他交互面的块（HTML 块、解析不出结构的块）直接点击即可进入源码编辑。图表和媒体通过就地源码编辑修改；块级公式可直接点击打开带预览的公式编辑框。手柄隐藏时不会拦截点击，左侧留白仍可用来定位。

**校对标记**：校对结果会在对应正文下方显示波浪线；高亮不改变正文内容。切换文档或正文发生变化后，过期标记自动清除；详细说明和修复操作仍在校对面板中。

**查找替换**：活动栏「搜索」、`Ctrl+F` / `Ctrl+H` 使用当前文档搜索面板，支持大小写与正则表达式。

**已知限制**

- 自动识别覆盖上述常用标记；包含未完成分隔符的复杂混合输入保持字面文本，可用工具栏排版或切换源码模式；转换后继续输入可能延续当前格式，可用方向键移出；
- 所见即所得不提供源码编辑器的多光标操作；
- 图表通过块源码的就地编辑修改；含代码、HTML、表格或分隔线等专用结构的列表/引用保持只读渲染，通过块菜单修改；
- 较旧的系统网页组件若不支持文字高亮，会仅显示校对面板；
- Markdown 不表达真正的末尾空引用段落，外部重新渲染时可能收起该空段落。

## 工具栏

工具栏按钮均为文字标签，分三组；**选中文本后**会浮现完整的选区工具栏。在 `设置 → 编辑器 → 固定显示编辑快捷栏` 开启后改为常驻。

| 分组 | 按钮 | 作用 |
| --- | --- | --- |
| 格式 | 加粗 / 斜体 / 删除线 | 包裹 `**…**`、`*…*`、`~~…~~`（也可用 `Ctrl+B` / `Ctrl+I`） |
| 格式 | 样式 ▸ | 高亮 `==…==`、下划线 `<u>`、上标 `<sup>`、下标 `<sub>` |
| 格式 | 标题 ▸ | 一至六级标题 |
| 格式 | 列表 ▸ | 无序 / 有序 / 任务列表、增加缩进 |
| 编辑 | 撤销 / 重做 | Monaco 撤销重做 |
| 编辑 | 整理 ▸ | 减少缩进、清除行内格式、**检查并格式化 Markdown**（先预览问题清单再应用） |
| 插入 | 表格 | 网格拖选行列插入 |
| 插入 | 插入 ▸ | 链接、图片、视频/音频、Emoji、代码块、引用、分割线、目录、折叠内容、注释、分页符 |
| 插入 | 公式 ▸ | 行内公式、公式块、脚注 |
| 插入 | 图表 ▸ | Mermaid 模板与 Markmap 思维导图 |

## 快捷格式化

- `Ctrl+B` / `Ctrl+I`：加粗 / 斜体（对选中文本生效）；
- `Ctrl+K`：创建 / 编辑链接——剪贴板里是 URL 时自动填入；
- 右键菜单「格式 ▸」：加粗、斜体、删除线、高亮、下划线、上标、下标、行内代码、清除行内格式。

## 智能 Tab 导航

（`设置 → 编辑器 → 启用自动配对与 Tab 跳出`，默认开启）

输入括号 / 引号自动补对（含中日韩括号 `「」『』（）【】《》` 与弯引号），`Backspace` 可删除空符号对；`Tab` 键按以下优先级在标记间穿梭：

1. `(文字|)` → 跳过闭合括号；`"文字|"` → 跳出引号；
2. `**加粗|**`、`__`、`~~`、`==`、`*`、`_`、`^` → 跳出行内格式标记；
3. `[文字|](链接)` → 先进入链接字段，再 `Tab` 跳出。

嵌套时每次只跳一层；多光标各自独立；**代码块与行内代码内自动停用**。

## 表格编辑

- **插入**：`Ctrl+Shift+T`（3×3）、工具栏网格拖选、`/table` 命令、右键菜单；
- **浮动工具栏**：光标进入表格即出现——插入 / 删除行列、左中右对齐、整理格式（按列宽补齐空格）、删除整表；
- **键盘**：`Tab` / `Shift+Tab` 切换单元格（末格 `Tab` 自动加行）；`Enter` 在下方新增一行；方向键移动；
- 「功能 → 表格操作」子菜单提供同样的 11 项操作；
- 预览中可拖动表头分隔线调整列宽，双击恢复自动宽度。

## 内联弹窗

在编辑器中**点击**链接 / 图片 / 公式 / 脚注 / Wiki 链接，会原位弹出编辑小窗（`设置 → 编辑器 → 启用内联弹窗`，默认开启）：

| 目标 | 弹窗能力 |
| --- | --- |
| 链接 | 修改 URL、打开、复制、移除链接 |
| 图片 | 浏览本地替换、复制、删除，尺寸属性保留 |
| 公式 | KaTeX 实时预览，随光标自动开合 |
| 脚注 | 跳转到定义、删除；无定义时确认会自动在文末创建 |

`Enter` 确认、`Esc` 关闭；**`Ctrl+点击` = 直达**（macOS 为 `⌘+点击`：链接用系统浏览器打开、脚注跳到定义）。

预览与源码模式中，鼠标悬停脚注引用 `[^1]` 会弹出定义内容，不需要跳到文末；没有定义的引用显示为虚线。

## 双向链接与反向链接

用 Obsidian 风格的 wiki 链接在笔记之间跳转：

| 写法 | 效果 |
| --- | --- |
| `[[笔记名]]` | 打开同名笔记 |
| `[[笔记名\|别名]]` | 显示「别名」，打开同名笔记 |
| `[[笔记名#标题]]` | 打开并滚动到该标题 |
| `[[#本文标题]]` | 跳到当前文档的标题 |
| `[[#^块id]]` | 跳到带 `^块id` 的段落 |

- 预览中单击即可打开并定位；源码对照与所见即所得使用 `Ctrl+点击`（macOS `⌘+点击`），普通点击仍是内联弹窗。
- 目标不存在时链接显示为虚线，点击后状态栏给出提示；重名笔记优先取当前文档目录，歧义目标保持未解析。
- 侧栏「大纲」下方的**反向链接**面板列出引用当前文档的文件、首次命中的行号与摘录，展开面板或切换文档时刷新。
- 暂不支持 `![[嵌入]]` 与自动补全，也无法输入字面 `[[…]]`。

## 富文本粘贴

从网页、Word 等复制的富文本，`Ctrl+V` 时自动转换为 Markdown 插入，保留标题、列表、链接等语义；`Ctrl+Shift+V` 粘贴为纯文本；右键「复制为」可把选区复制为 HTML。

## 编辑器右键菜单

右键会把光标移到点击处，菜单包含：AI 润色 / AI 翻译（需选区）、撤销重做、剪切复制粘贴、复制为（HTML / 纯文本）、粘贴为纯文本、全选、格式 ▸、标题 ▸（1~6 级）、插入 ▸、表格 ▸（完整行列操作）、导出（PDF / Word / HTML）、在文件夹中显示。

## Emoji 与常用表情

工具栏「插入 → Emoji」打开选择器；顶部的常用表情可在 `设置 → 编辑器 → 常用表情` 自定义（最多 24 个）。

## 查找与替换

**当前文档（推荐）**：活动栏切到「搜索」视图，直接针对**正在编辑的正文**查找与替换：

- 输入关键词即出命中列表（行号 + 整行文本），点击定位；输入框 `Enter`（下一个）/ `Shift+Enter`（上一个）或头部 ↑ / ↓ 在命中间循环；
- `替换` 替换当前命中，`全部替换` 替换全部（带确认对话框）；
- 选项：**区分大小写**、**正则**；正则替换支持 `$1` 等分组引用；
- 只作用于当前文档，**未保存的修改也能搜到**；替换通过编辑器写入，**保留撤销历史**，一次 `Ctrl+Z` 即可回退。

**编辑器内置查找**：`Ctrl+F` 打开查找框，`Ctrl+H` 切换到替换模式。

**跨文件搜索与快捷命令**：标题栏搜索框或 `Ctrl+P` 打开顶部统一搜索栏——空输入时先列出**前 5 条快捷命令**（新建文件、检查链接、演示模式、沉浸阅读 / 写作、导出等，右侧显示快捷键）与**近期文件**；末尾「更多命令…」或输入 `>` 进入命令模式，可按名称筛选全部命令；输入关键词后搜索已打开的文档、当前文档正文、工作区文件名与文件内容。详见[文件与工作区](/guide/files)。

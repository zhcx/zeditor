# 云备份（WebDAV / S3）

Zeditor 支持在本地保存成功后，**自动**把文档备份到你自建的 WebDAV 服务器或 S3 兼容对象存储。配置在 `设置 → 云同步`，**两者可同时启用**，各自独立队列与状态。

::: tip 本地优先
云端备份失败**不影响本地保存**——文档永远先落在你自己的磁盘上，云端只是副本。
:::

## WebDAV 备份

1. 开启「启用 WebDAV 自动备份」；
2. 填写：服务器地址（如 `https://example.com/dav`）、用户名、密码 / 应用密码、远端根目录（默认 `/Zeditor`）；
3. 点「测试连接」验证凭据。

::: warning 凭据安全
WebDAV / S3 凭据仅保存在本地设备，不会上传到任何第三方服务。
:::

## S3 兼容存储备份

支持 AWS S3、阿里云 OSS、腾讯云 COS、华为 OBS、MinIO、Cloudflare R2 等：

1. 开启「S3 云同步」；
2. 填写：服务端点、存储桶、地域、Access Key / Secret Key、远端根目录（默认 `/Zeditor`）；
3. 自建 MinIO 等未开虚拟主机域名服务时，开启「Path-Style 路径风格」；
4. 点「测试连接」验证。

## 版本策略

- 每次本地保存成功后自动在后台入队上传；
- 保留**最新副本 + 最近 20 个不同内容版本**（按 SHA-256 去重，内容相同不重复占用）；
- 失败任务持久化，应用重启后自动恢复上传。

## 查看与恢复

- **状态栏**实时显示同步状态，点击可重试；
- 「**浏览全部备份**」打开历史对话框，按时间列出各版本；
- 历史版本通过「另存为」下载恢复，**下载前校验哈希**，确保内容完整。

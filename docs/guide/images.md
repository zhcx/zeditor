# 图片

Zeditor 支持本地图片、网络图片与图床上传三条路径，并自动处理存储位置，让文档离线也能正常显示。

## 插入图片的三种方式

1. **对话框**：`Ctrl+Shift+I`、工具栏「插入图片」、右键菜单「插入 → 插入图片」或 `/image` 命令，在弹窗中选择：
   - **本地图片**：复制到文档同级 `.assets` 目录后插入相对路径；
   - **网络链接**：直接填写图片 URL；
   - **上传图床**：上传到已配置的图床服务后插入外链。
2. **拖拽**：把图片文件直接拖进窗口，自动复制到 `.assets` 并插入。
3. **粘贴**：截图或复制的图片直接 `Ctrl+V`，桌面端优先写入 `.assets`；未配置时降级为图床上传。

::: warning 请先保存文档
插入**本地图片**前需要先用 `Ctrl+S` 保存一次文档——图片会复制到文档同级的 `.assets` 目录，未保存的文档没有归属目录。
:::

## `.assets` 目录规则

- 所有本地导入的图片与音视频素材都复制到**文档同级的 `.assets` 目录**，插入相对路径，例如 `![封面](.assets/cover.png)`，因此文档移动或离线后图片依然可见；
- 同名同大小的文件视为同一素材直接复用，否则自动追加 `-1`、`-2` 序号。

## 调整图片尺寸

**尺寸语法**：在图片后面加大括号，只接受纯像素数字：

```markdown
![替代文本](.assets/cover.png){width=420}
![替代文本](.assets/cover.png){width=320 height=200}
```

**在预览中操作**：

- **双击**图片：打开「图片属性」弹窗，编辑路径、替代文本与尺寸；
- **右键**图片：快速设置小 (240px) / 中 (420px) / 大 (640px) / 原始尺寸、编辑属性、复制路径、删除图片。

尺寸只回写到语法中，不会改动图片文件本身。

## 图床服务

在 `设置 → 图床` 中选择启用的服务（默认「本地」）：

| 服务 | 需要配置 |
| --- | --- |
| 本地 | 保存目录（默认 `./assets/images`）、命名规则（时间戳 / UUID / 原始名称） |
| Cloudinary | 云名称、API Key、API 密钥、上传文件夹 |
| PicGo | PicGo 服务器地址（默认 `http://127.0.0.1:36677`） |
| S3 / OSS | 阿里云 OSS、AWS S3、腾讯云 COS、华为 OBS、MinIO 或自定义端点、桶、地域、密钥 |

上传进度显示在状态栏。

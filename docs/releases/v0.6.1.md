# Zeditor v0.6.1

> 发布日期：2026-10-07

本版本完善顶部搜索体验：**空输入即可见「快捷命令」与「近期文件」**，搜索输入框移入标题栏（面板只负责列出结果），并收紧面板行距、统一输入框样式。

## 更新日志

### 搜索

- **快捷命令**：空输入时列出前 5 条常用命令——新建文件、搜索当前文档、检查链接、AI 指令面板、演示模式、分屏 / 沉浸阅读 / 沉浸写作、导出为 HTML / Word、设置，右侧显示快捷键。末尾「更多命令…」进入命令模式（或直接输入 `>`），可按名称筛选全部命令。命令用词与快捷键沿用「文件 / 功能」菜单，保持与菜单一致。
- **近期文件**：空输入时列出最近打开过的文件（文件图标 + 文件名 + 灰色父目录路径），点击直接打开；与侧边栏「近期记录」**共用同一份数据**。
- **输入框移入标题栏**：`Ctrl+P` 展开后输入框就在标题栏原地出现，面板只负责列出结果，**不再出现第二个搜索框**；提示行改为单行显示、空间不足时省略，不再换行撑高面板。
- **面板密度与样式**：压缩行距与高亮块（命令行 26px、近期文件 28px、命中行 26px、文档行 40px），分组间距同步收紧；输入框去掉自绘底色与内圈描边，只保留外层一圈蓝色边框，与侧栏查找框等既有输入框保持一致。

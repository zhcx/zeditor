# Zeditor v0.6.0

> 发布日期：2026-10-07

本版本重构了搜索体系：新增**顶部统一搜索栏**（打开的文档 / 当前文档正文 / 工作区文件 / 工作区内容）与**侧边栏「搜索当前文档」**（正文查找与替换）两个入口，并修复了工作区检索报错、搜索卡死与编辑器查找框多余描边；同时压缩了资源管理器的视觉密度。

## 更新日志

### 搜索

- **顶部统一搜索栏（`Ctrl+P`）**：标题栏搜索入口改为锚定其下方的下拉面板，一次输入即可搜索四类目标——**已打开的文档**、**当前文档正文命中**、**工作区文件名**、**工作区文件内容**。`↑` / `↓` 选择、`Enter` 打开、`Esc` 收起，点击面板外部自动关闭。
- **即时层，边输边出**：已打开文档的正文命中（含**尚未保存**的修改）与工作区文件名都不读磁盘、不做全盘扫描，输入即可见结果。
- **侧边栏「搜索当前文档」视图**：活动栏搜索按钮切到该视图，针对**当前正在编辑的正文**做查找与替换——命中列表（行号 + 整行文本）、上一个 / 下一个、`替换`、`全部替换`（带确认）、区分大小写、正则（替换支持 `$1` 分组引用）。替换通过编辑器 API 写入，**保留撤销历史**，一次 `Ctrl+Z` 即可回退。
- **工作区检索性能修复**：新增工作区文件清单缓存（10 秒内复用，仅遍历元数据）、文件名内存匹配，内容检索按「路径命中 → 最近修改」排序，并施加 1500 文件 / 2 秒的双重预算；发起新检索时旧检索立即中止。修复了此前「搜索极慢、整机卡死、一直显示搜索中」的问题。
- **修复工作区检索报错**：搜索参数名与后端结构体不一致，导致 `Invalid args options for command workspace_search: missing field case_sensitive`，工作区文件名与内容检索无法使用；现已统一为后端字段名。
- **修复编辑器查找框多余描边**：`Ctrl+F` 内置查找框不再出现一圈蓝色焦点描边。

### 界面

- **侧边栏密度优化**：压缩资源管理器各分组行高与分组间距，整体更紧凑，视觉密度贴近 VS Code。
- **修复「近期记录」空状态**：分组为空时的占位文案原先缺少缩进、紧贴左边缘；现已与「近期记录」标题文字对齐，避免换行。
- **重构文档切换器与文件树**：重写多标签页文档切换器，精简侧边栏文件树交互，提升多文档导航与切换体验。
- **界面与本地化打磨**：完善活动栏、标题栏与多语言文案细节。

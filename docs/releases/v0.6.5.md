# Zeditor v0.6.5

> 发布日期：2026-10-18

这是以「写作手感」为主的一次升级：新增**按比例限制行宽、折叠标题 / 折叠缩进、缩进参考线**与状态栏视图状态按钮；补齐 **Obsidian 双向链接**与**脚注悬停预览**；并完成一轮稳定性审查，修掉脚注定义、Wiki 路径、异步导航、反向链接扫描与 macOS 菜单/CLI 的一批边界问题。

## 更新日志

### 新增：行宽与折叠（编辑显示）

- **比例行宽**：改为「各编辑框自身宽度的 40%–100%」，默认 80%，步长 1%。源码卡片、阅读预览、所见即所得与沉浸阅读按各自面板宽度计算，分屏、缩放窗口、切换模式都不再出现某一侧被固定像素卡住的情况；旧的 480–2400px 设置会在读取时回退为 80%，其余设置不受影响。
- **`Ctrl+滚轮` 调行宽**（macOS `⌘+滚轮`）：上滚调宽、下滚调窄，每累计 100px（约 3 行或 1 页）为一档 2%，触控板小增量会累加；短暂显示当前百分比。关闭「限制行宽」时首次收窄会自动开启。设置、菜单、对话框、已有 SVG / 工作流画布内的缩放不受影响，触控板捏合也不会误触发。
- **设置 → 编辑器 → 显示设置**：限制行宽 + 行宽滑块、折叠标题、折叠缩进、缩进参考线、视图状态按钮。显示类开关即时生效，不必等「保存」；`Esc` 关闭设置面板（等价「取消」，同时撤回未保存的预览）。
- **折叠标题**：源码对照由 Monaco 折叠范围提供（标题到下一个同级或更高级标题之前），行号栏悬停出现折叠箭头；所见即所得在标题左侧显示折叠箭头，折叠整段正文，箭头在折叠后常驻。`Ctrl+Alt+[` / `Ctrl+Alt+]`（macOS `⌘⌥[` / `⌘⌥]`）折叠 / 展开当前标题。
- **折叠缩进**：源码对照按 2 空格缩进生成独立折叠块（空行与代码围栏边界安全，单子项也能折叠）；所见即所得点击列表项标记区折叠子项，项目符号变 `▾` / `▸`。
- **缩进参考线**：源码对照使用 Monaco 缩进参考线，所见即所得在嵌套列表左缘画竖线。
- **状态栏**：新增视图状态按钮（源码对照 ↔ 所见即所得，可在显示设置中关闭）；保存状态移到状态栏最左，绿 / 黄 / 蓝三色圆点 + 悬停说明（已就绪、未保存修改、保存中…、已保存）。
- **折叠与光标**：折叠时若光标落在被隐藏的块里会回到标题行首；Enter 新段落、撤销重做或外部定位让光标落入折叠区时自动展开相关标题；所见即所得的折叠状态按标签保存在本次会话内，切换模式或标签回来仍然保留。

### 新增：Obsidian 双向链接

- 语法：`[[笔记]]`、`[[笔记|别名]]`、`[[笔记#标题]]`、`[[笔记#标题|别名]]`、`[[#本文标题]]`、`[[#^块id]]`。
- 渲染：预览与所见即所得把 wiki 链接渲染成内联链接（代码块与行内代码不受影响）；未解析的目标显示虚线，点击失败在状态栏提示。
- 打开：阅读预览单击即可打开目标笔记并定位到标题 / 块；源码与所见即所得使用 `⌘` / `Ctrl` + 点击，普通点击仍是原有的链接编辑弹窗。
- 反向链接：侧栏「大纲」下方新增反向链接面板，列出引用当前文档的文件、首次命中行与摘录；扫描有 30,000 目录项 / 2000 文件 / 单文件 2MB 预算，忽略 `.git`、`node_modules`、`.obsidian` 等目录，同一请求会合并，最多 4 个并发扫描。
- 输入即渲染：在所见即所得中输入 `]]` 闭合时当场变成链接元素，回写仍保留别名；表格中的 `|` 会正确转义。

### 新增：脚注悬停预览

- `[^name]` 在正文渲染为上标引用，悬停（或键盘聚焦）显示定义内容，浮层支持鼠标移入、滚动与缩放时自动收起。
- 源码对照在 `[^name]` 上悬停同样显示定义；定义按文档版本缓存。
- `[^name]: 内容` 定义行在预览中保持原文，不再被当成普通链接定义；支持 4 空格 / Tab 续行、空行与围栏代码内的忽略规则；多行定义通过块源码就地编辑，保留空格、Tab 与空行续行。
- 所见即所得输入 `[^name]` 闭合时即时转换为引用元素，行首定义仍保持文本，避免破坏定义。

### 新增：块菜单扩展

- 块菜单前两项改为「转换为 → 在下方插入」：转换支持正文、1–6 级标题、无序 / 有序 / 任务列表、引用、代码与公式；插入覆盖正文、全部六级标题、列表、引用、代码、公式、表格、图片、链接、视频 / 音频、分隔线、折叠内容、目录、注释，以及流程 / 甘特 / 时序 / 状态 / 类图与思维导图。
- 空任务与空公式使用可替换占位内容；媒体、公式、注释等只读块插入后自动打开块源码编辑并选中可修改部分（`Ctrl+Enter` 保存、`Esc` 关闭）。本地图片沿用 `.assets` 导入服务，插入位置就是所选块的下方，取消对话框不会修改文档。

### 新增与改进：macOS 体验

- `⌘+滚轮` 调行宽（排除触控板捏合）、`⌘+点击` 打开链接、原生菜单补「编辑 → 查找…」`⌘F`、`⌘⌥[` / `⌘⌥]` 折叠、小屏右键菜单按实测高度夹紧、`prefers-reduced-transparency` 下关闭半透明模糊。
- `Info.plist` 补 `LSApplicationCategoryType` 与 `NSHumanReadableCopyright`；更新检查识别 `_universal.dmg`，更新弹窗区分 DMG / AppImage / deb。
- 签名：去掉强制 ad-hoc identity，改为按 CI 中实际配置的 `APPLE_*` 变量决定签名与公证，凭证不完整时提前失败；辅助程序先于主程序签名。未配置证书时安装包仍未签名、未公证。
- Agent CLI：macOS GUI 进程补齐 `/opt/homebrew/bin`、`/usr/local/bin`、volta / cargo / nvm 等路径，绝对路径能发现但子进程找不到 Node / Homebrew 的问题不再出现。

### 性能

- 所见即所得每次按键跳过不必要的 DOM → Markdown 序列化与布局测量（光标折叠、非表格、块内无 `/` 时直接返回）。
- 250ms 写回先做单块解析：结构稳定时只更新该块并平移后续偏移，不再每次跑全文 `markdown-it`；类型或覆盖范围变化时自动退回全文解析。
- 标题折叠计算改为栈扫描 + 预计算，Monaco 折叠范围按「model + 版本 + 开关签名」缓存；设置面板拖动行宽不再每帧重渲染整块面板，长文档拖动时冻结 Monaco 布局、松手精确重排一次。
- 状态栏不再订阅正文、字数统计 160ms 防抖、分屏滚动同步改为 80ms 防抖重建；Monaco 启用大文件优化、限制 token 化行数与渲染行数。

### 修复（稳定性审查）

- 增量分块：修复相邻列表合并、未闭合围栏 / HTML 吞块、Setext 标题边界、清空段落与换行变化导致后续块位置与全文解析不一致；快路径只用于换行、缩进和结构都稳定的段落 / 标题。
- 脚注：修复 `[^n]: 单词` 被当作链接定义、公式预处理把定义原文变成 KaTeX、定义括号与下划线名称被转义、Enter 分割破坏前缀、多行续行缩进丢失，以及逐块渲染时拿不到其他块定义、定义更新后浮层过期。
- Wiki / 脚注光标：原子元素映射到源码两侧、点击落入所指元素内部偏移；结构编辑前吸附到原子边界，Enter 不再克隆半个原子。
- 标题折叠：末尾空标题上的折叠快捷键不再折叠前一个无关章节。
- Wiki 解析：其他目录的同名笔记不再抢占当前目录目标，显式错误路径不再退化成任意同名文件，支持 `.markdown`；歧义目标保持未解析。
- 异步导航：慢解析 / 慢读取不再打断用户已切换的标签，编辑器正文就绪后才定位。
- 反向链接：代码与注释里的示例不再被算作引用；空结果保留刷新入口；浏览器预览不再进入永久加载状态。
- macOS 菜单：原生菜单点击时读取最新菜单动作（不再保存旧正文闭包），原生加速键生效时窗口监听让位，过期菜单安装被取消。

### 实现说明

- 显示设置集中在 `src/utils/editorDisplay.ts`（百分比归一化、滚轮换算）与 `src/styles/reading-view.css`；源码模式由 `src/utils/markdownFolding.ts` + `Editor.tsx` 的折叠 provider 驱动，所见即所得由 `src/utils/wysiwyg/headingFolds.ts` + `WysiwygEditor.tsx` 驱动。
- 双向链接解析在 `src/utils/wikiLinks.ts` 与 `src/services/wikiLinks.ts`，反向链接扫描命令为 Rust `find_wiki_backlinks`；脚注解析在 `src/utils/footnotes.ts`，渲染规则在 `src/utils/markdownPipeline.ts`，浮层在 `src/utils/markdownEnhancers.tsx`。
- 本轮验证：TypeScript、ESLint、`npm run build`、`cargo fmt --check`、`cargo clippy --locked --all-targets -- -D warnings`、`cargo test --locked`（182 项通过，3 项原有忽略）全部通过；前端 687 项测试通过；隔离 Edge 浏览器回归 44 个场景通过。
- 审查记录见仓库 `docs/reviews/2026-10-18-stability-audit.md`。

### 已知限制

- 双向链接暂不支持 `![[嵌入]]`、自动补全，也无法输入字面 `[[…]]`；重名笔记取当前文档目录或工作区中的第一个匹配；导出 PDF / HTML 中链接不可跳转。
- 反向链接不是实时索引：展开面板、切换文档或手动刷新时才扫描，超大工作区首次扫描会较慢。
- 脚注定义行在预览中仍是普通文本，没有文末脚注列表排版；悬停浮层不支持点击固定。
- 折叠只发生在编辑视图，阅读预览与沉浸阅读不折叠；列表折叠状态保存在 DOM 上，块内容变化重建后会复位（源码不受影响）。
- macOS 安装包未配置 Apple 证书时不签名、不公证，首次打开需右键「打开」或在「系统设置 → 隐私与安全性」放行。

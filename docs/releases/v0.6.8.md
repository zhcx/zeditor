# Zeditor v0.6.8

> 发布日期：2026-11-03

本次更新新增中文排版和大文档轻量模式，改进跨模式编辑历史与阅读位置恢复，并修复所见即所得大纲跳转。

## 更新日志

### 中文排版

- 工具栏「整理 → 中文排版」支持对选区或全文调整中英文与数字间距、中文标点、全角字符和中文引号；应用前可预览，应用后可撤销。
- 排版保守跳过代码、链接、图片、公式、URL、HTML 标签和文首 YAML 等内容；优化密集行内语法的处理，并保护引用和列表内的多行公式。

### 大文档与编辑历史

- 根据文件大小、文档块和表格复杂度识别大型或结构密集的文稿，自动进入单栏轻量源码模式；可按标签切换回完整视图。
- 源码编辑与所见即所得共享当前标签的撤销、重做历史，切换编辑方式跟随光标，切换标签时恢复对应视图的阅读位置。历史在关闭标签、退出应用或重新读取磁盘文件后不再保留。
- 优化大文档渲染与历史快照处理；无实际变化的替换不再清除重做记录。

### 导航与交互修复

- 修复所见即所得模式点击左侧大纲后无法滚动到标题的问题；折叠或尚未渲染的目标会在展开和渲染后定位。
- 修复从应用菜单撤销时焦点可能转移、影响错误输入区域的问题。

# Zeditor v0.4.5

> 发布日期：2026-09-07

## 更新亮点

本版本聚焦 Agent / AI 对话与编辑器协同体验，同时修复资源管理器删除残留和 Monaco 单击后误触发灰色高亮的问题。

## 更新日志

### Agent 与 AI 对话

- **输入框即时清空**：提交 Agent 任务后立即清空输入框，不再等任务启动或执行结束；启动失败时恢复原输入，方便重试。
- **完全访问权限修复**：Claude 的“完全访问”模式使用 CLI 原生 `bypassPermissions`，不再重复弹出普通权限请求；越界访问和 `git push` 等硬性禁止操作仍会被拦截。
- **自动识别当前文档**：Agent 与 AI 对话打开后自动识别当前活动文档，显示为可移除的上下文标签；支持未保存文档，文档切换或编辑后同步最新内容。
- **上下文移除可靠**：移除当前文档标签后，本轮不再携带该文档内容；切换到其他文档后自动重新识别。
- **统一插入体验**：Agent 与 AI 回复均支持“插入编辑器”，插入内容前自动加入 Markdown 横线 `---`，并保留原有撤销和光标定位行为。

### 编辑器

- **关闭单击同词高亮**：关闭 Monaco 默认的 `occurrencesHighlight`，单击文字只移动光标，不再给文档中相同内容显示灰色块。
- 鼠标拖选、Shift 选区等真实文本选中行为保持不变。

### 资源管理器

- **删除列表刷新修复**：删除目录中的最后一个文件后，父目录刷新结果为空时也会正确更新内存树，残留节点立即消失。
- **打开文档删除提醒**：删除正在编辑的文档时显示明确提醒；确认后先删除磁盘文件，再自动关闭所有对应编辑标签。
- 删除失败或取消时保留原编辑器和资源管理器状态。

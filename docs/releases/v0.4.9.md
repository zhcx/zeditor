# Zeditor v0.4.9

> 发布日期：2026-09-22

本版本聚焦写作中最常用的两类结构化内容：表格可以直接在编辑器里增删行列、切换对齐与拖动列宽，图片则统一走文档同级的 `.assets` 目录，支持尺寸、双击编辑与右键调整。

## 更新亮点

### 表格编辑

- **统一插入入口**：工具栏网格拖动、功能菜单、`Ctrl+Shift+T` 与斜杠命令 `/table` 复用同一份表格源码，默认 3 × 3，光标落在表头第一个单元格。
- **浮动操作工具栏**：光标进入表格即出现工具栏，可上 / 下插入行、删除行、左 / 右插入列、删除列、切换左 / 中 / 右对齐、整理格式（按列宽补齐空格）以及删除整张表格。
- **键盘导航**：Tab / Shift+Tab 切换单元格（末行按 Tab 自动补一行），方向键在单元格之间移动，Enter 在当前行下方新增一行；光标不在表格内时按键行为保持不变。
- **预览列宽拖动**：拖动表头右侧分隔线调整列宽，双击把手恢复该列的自动宽度。Markdown 没有列宽语义，列宽只作用于预览视图，不写入文档。

### 图片支持

- **统一素材目录**：文件对话框、拖入窗口与粘贴剪贴板三条路径都会把图片复制到文档同级的 `.assets` 目录，离线可看，不依赖图床配置。
- **尺寸语法**：新增 `![替代文本](路径){width=420 height=280}`，预览按指定像素渲染，非法值原样保留。
- **双击编辑**：双击预览中的图片可修改源路径、替代文本、标题与显示尺寸；右键菜单支持 240 / 420 / 640 像素、恢复原始尺寸、复制路径与删除图片。
- **缺失提示**：本地图片找不到时在预览中显示「无法读取图片：路径」提示卡片，替代文本与标题语义保持不变。

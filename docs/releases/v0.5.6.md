# Zeditor v0.5.6

> 发布日期：2026-09-30

本版本聚焦 **Agent 交互响应性能** 与几处界面打磨：用户输入到首个反馈显著加快，长回答流式输出期间输入框保持流畅；同时修复窄窗口下 Agent 输入框工具栏文字重叠、侧栏标题被截断与主题子菜单溢出问题。

## 更新亮点

### 1. Agent 交互响应性能优化

- **启动链路并行**：隔离工作区准备（git worktree + 基线提交）与 CLI 能力探测不再串行，两者并行执行；探测内部的版本与能力两次 CLI 冷启动也并行；仓库全量文件哈希按可用并行度分片并行，万级文件仓库由数秒降到亚秒级。
- **即时进展提示**：隔离工作区准备与 CLI 冷启动合计可达数秒，期间新增 `emit_progress` 状态事件——「正在准备隔离工作区…」「正在启动 …」，提交后界面立即显示进展，不再长时间无反馈。
- **流式渲染合并**：逐 token 事件改为按 `requestAnimationFrame` 合并为一次渲染；时间线分组 `buildTimelineBlocks` 用 `useMemo` 缓存；`AgentMarkdown` 按固定节奏（80ms）追赶最新内容，避免长回答期间每 token 重排导致的卡顿与输入发涩。

### 2. 窄窗口 Agent 输入框工具栏换行

- 未最大化窗口下，「+ / @引用 / 审批 / 模型 / 推理强度 / 发送」以可读最小宽度换行（`flex-wrap`），不再因控件被挤扁而文字重叠；模型 / 推理强度 / 发送这组在换行后仍贴右显示。

### 3. 侧栏默认宽度修正

- 新会话默认侧栏宽度由 220px 提升到 250px，资源管理器标题「资源管理器」完整可见，不再被省略号截断。

### 4. 主题子菜单溢出修复

- 视图 → 主题列表靠近视口底部时自动向上翻转，12 套主题（6 浅色 + 6 深色）不再被裁切；内层滚动兜底长列表。

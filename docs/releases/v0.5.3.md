# Zeditor v0.5.3

> 发布日期：2026-09-29

本版本带来两项核心能力：**AI / Markdown 双模式校对** 与 **Markmap 思维导图**。前者让「校对」在没有配置 AI 时也能稳定工作，后者把标准 Markdown 标题层级渲染成可交互的思维导图。

## 更新亮点

### 校对功能：AI / Markdown 双模式

「设置 → AI 助手」新增「使用 AI 校对」开关：

- **开启（默认）**：「校对」按钮调用 AI 模型，行为与原先一致。
- **关闭，或 AI 未配置**：改用内置 **Markdown 静态校对**，检查未闭合围栏、反向链接、跳级标题、断开的锚点、表格列数不匹配、空链接等问题。规则编号对齐 VMark 的 lint 设计，只查正确性、不做样式强制。
- 静态校对结果与 AI 校对**同构**：同一个侧栏面板、同一套编辑器波浪线装饰与「应用修复」交互；`report-only` 的问题只提示、不显示应用按钮。
- 状态栏「校对」不再自动启用 AI；AI 校对开启但不可用时给出明确的设置引导提示。

### Markmap 思维导图

- 新增 **Markmap 思维导图**：`markmap` 代码围栏里的标准 Markdown 标题层级（`#` / `##` / `###`）渲染为可交互 SVG 树，支持拖动平移、`Ctrl` + 滚轮缩放、点击分支圆圈折叠、适应视图与 2 倍分辨率 PNG 导出。
- 配色跟随明暗主题；节点内容在写入 `foreignObject` 前按预览同一套规则清洗；markmap 解析与渲染库在首次遇到围栏时才按需加载，不进入首帧关键路径。
- 插入入口共用同一份模板并默认选中中心主题：`/markmap` 斜杠命令、工具栏「图表 → Markmap 思维导图」、「功能 → 插入思维导图」；Markdown 语法指南新增对应示例。

### 修复

- 修复状态栏「校对」在 AI 未配置时强制占用 AI 通道、导致无界面提示的问题；当前模式在状态栏与设置中均有明确说明。

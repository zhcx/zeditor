# Zeditor v0.5.1

> 发布日期：2026-09-24

本版本带来一次完整的界面升级：明暗双主题按简约现代理念重新设计，圆角、阴影、焦点与滚动条全部统一；菜单栏可直接看到当前主题与模式；编辑器新增智能 Tab 导航，Tab 能在括号、引号、行内格式与链接之间穿梭。

## 更新亮点

### 界面焕新（明暗双主题重设计）

- **配色重校**：浅色主题为纯净中性灰底 + 现代钴蓝强调（`#2d6ae0`）；深色主题为深炭灰基调 + 鲜明天蓝强调（`#58a6ff`）；文本三级对比度、边框透明度与语义色（成功 / 警告 / 危险）在双主题下统一协调。
- **形状语言现代化**：控件圆角 3px → 6px、容器 8px、浮层 12px；阴影改为冷调低透明分层；过渡时长统一为 120ms / 180ms，交互更顺滑。
- **焦点与滚动**：按钮与输入框使用 2px 强调色焦点环，输入框聚焦带 3px 淡色光环；滚动条改为悬浮细条，悬停时加深，编辑器与工作区观感一致。
- **语法高亮**：浅色采用 One Light 风格（紫关键字 / 绿字符串 / 蓝类型 / 橙数字），深色采用 GitHub Dark 风格（红关键字 / 蓝字符串 / 紫类型 / 橙数字）。
- **编辑器配色统一**：编辑区背景、行号、当前行、光标与选区全部与工作区主题同源，切换主题零色差；修复浅色主题下编辑区文字偏淡难以辨认的问题。
- **无缝启动**：演示模式、启动画面与原生窗口背景同步新主题色，明暗启动均无白屏闪烁。

### 菜单栏

- **当前项标识**：主题（深色 / 浅色）与模式（分屏 / 沉浸阅读 / 沉浸写作）菜单显示当前选中项 ✓，一眼看出当前状态。
- **交互统一**：所有菜单项点击后统一收起菜单，修复模式切换后菜单悬浮不消失的问题；沿用悬浮菜单的延迟收起与二级子菜单桥接。

### 智能 Tab 导航

- **括号与引号跳出**：光标紧邻闭合括号 / 引号之前时按 Tab 跳到其后，支持 `()`、`[]`、`{}`、`""`、`''`、中日韩括号（`（）【】「」『』《》〈〉`）与弯引号（`“”‘’`）；嵌套时每次只跳出一层（`((n|))` 需按两次）。
- **行内格式跳出**：光标位于 `**粗体**`、`*斜体*`、`__下划线__`、`~~删除线~~`、`==高亮==`、`^上标^` 区间内任意位置时，Tab 跳到闭合标记之后。
- **链接字段导航**：`[文字|](地址)` 按 Tab 进入 URL，URL 内任意位置再按 Tab 跳出整个链接。
- **优先级与保护**：由内而外处理（链接字段 → 括号 / 引号 → 行内格式）；代码块与行内代码内全部停用；转义括号（`\(a\)`）与空白分隔的标记（`2 * 3 * 4`）不会误跳出。
- **多光标支持**：每个光标独立判定，可跳出的光标前移、普通位置保持不动；可跳出的光标前移后其余光标继续保留，配合多选批量编辑更高效。
- **键盘约定**：Shift+Tab 保持取消缩进（表格内为跳到上一个单元格），与表格导航按上下文自动分流。

### 修复

- 修复浅色主题下编辑区文字偏淡、难以看清的问题（编辑器配色改为与工作区完全同源）。
- 修复模式切换（分屏 / 沉浸）后菜单悬浮不消失的问题。

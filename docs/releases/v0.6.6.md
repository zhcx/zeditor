# Zeditor v0.6.6

> 发布日期：2026-10-21

本次更新加强文稿恢复与保存保护，支持备份文稿引用的本地图片和媒体，新增可编辑的 Word 导出，并让图表进入各类导出结果。

## 更新日志

### 文稿恢复与保存保护

- **异常退出恢复**：应用会保存文稿恢复快照；重新启动后可找回未保存的草稿。快照有短暂防抖，并受现有容量和保留期限限制，不是逐字实时记录。
- **外部修改冲突提示**：保存时检测磁盘版本；若其他程序已修改文稿，会保留本地草稿并提示重载磁盘内容或另存处理，避免静默覆盖。
- **回收站与恢复**：从资源管理器删除的项目优先进入系统回收站；系统不可用时尝试存入 Zeditor 恢复区。可在「回收站与恢复」查看 Zeditor 自己的删除记录并恢复。同名路径已存在时拒绝覆盖。macOS 系统废纸篓项目请在访达中恢复。
- **可靠性修复**：加固并发保存、恢复快照、附件清理、文稿关闭和应用退出时的任务处理，降低旧任务影响新内容的风险。

### WebDAV / S3 图文备份

- 备份现在可包含文稿引用的同级 `.assets` 图片、音视频等附件；附件全部上传并通过校验后，才标记该版本为完整备份。
- 可以将完整备份恢复到新文件夹，保留文稿原始字节与附件相对路径，离线时仍可打开相关图片和媒体。
- 备份只收集文稿实际引用的同级 `.assets` 普通文件，不上传任意本地目录或网络地址。附件大小和数量限制、凭据安全及恢复细节见[云备份指南](https://github.com/zhcx/zeditor/blob/main/docs/guide/cloud-backup.md)。

### Word 与图表导出

- Word 导出生成真正可继续编辑的 OOXML `.docx`，支持标题与常用文字样式、列表、表格、超链接、脚注、目录、页眉页脚和文档内图片。
- Mermaid、Markmap、SVG 围栏和 GitHub Actions 工作流图表会渲染到 HTML、PDF、长图、公众号和 Word。单个图表渲染失败时保留该处源码并提示，其他内容仍可导出。
- 长图和公众号导出会等当前文稿的图表渲染结束后才允许生成或复制；长图图表跟随当前生效的明暗主题。
- Word 公式仍以 TeX 原文保留；原始 HTML 和播放器等交互内容不会转换成 Word 布局。更多格式与图片限制见[导出指南](https://github.com/zhcx/zeditor/blob/main/docs/guide/export.md)。

### 编辑器与 macOS

- 「启用自动补全」现在即时控制 Monaco 的快速建议、触发字符建议和文档单词建议。
- 改进大文稿统计与所见即所得分批渲染、文档保存、DOCX 图片处理和 PDF 浏览器退出清理。
- 修复 macOS DMG 卷图标圆角和应用图标灰底板显示。
- 更新 Markdown 渲染、HTML 清洗与构建依赖的安全补丁版本。

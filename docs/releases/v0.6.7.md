# Zeditor v0.6.7

> 发布日期：2026-10-28

本次更新加强多设备云备份的并发安全与文件恢复可靠性，修复所见即所得编辑器选定文字后粘贴替换的标记残留问题，并继续优化渲染缓存与保存流程。

## 更新日志

### 云备份并发安全

- **条件写入**：WebDAV / S3 版本备份读取远端强 ETag，并用 `If-Match` / `If-None-Match` 发送条件写入；多台设备同时保存同一文稿时，冲突写入会重新读取远端清单并合并，而不是静默覆盖其他设备的备份。
- **签名与兼容**：S3 条件请求头纳入 SigV4 签名；并发创建远端目录时兼容部分服务器返回的 HTTP 500。
- **并发测试**：新增真实 WebDAV / S3 多设备并发测试（默认跳过，需显式配置），测试方法与服务器要求见[并发测试说明](https://github.com/zhcx/zeditor/blob/main/docs/testing-live-sync.md)。

### 文件、恢复与转换

- 回收站与文件恢复会校验根路径和文件名，异常路径不再导致命令线程 panic。
- 旧编码文本解码失败时明确报错，不再用替换字符写回并覆盖原文。
- 文件哈希改为流式读取，大文件保存时不再把完整内容重复读入内存；恢复快照替换改为原子操作。
- 文档转换器持续排空子进程输出，增加超时并回收子进程，转换异常时不再挂起应用。
- AI 流式响应在停止生成、切换会话或离开页面、客户端断开时取消，不再在后台继续接收。

### Markdown 渲染稳定性

- Mermaid 与 Markmap 块被替换时销毁旧实例，避免重复渲染竞争与残留。
- KaTeX 与代码高亮缓存按条目数和字节权重设置上限，长时间编辑大文档时内存占用更稳定。
- 修复代码高亮缓存键碰撞，不同内容不会再命中彼此的缓存。

### 所见即所得粘贴

- **选区替换不残留**：选中部分文字后粘贴替换，不再残留原来的 `**`、`~~`、反引号等标记；粗体、删除线、行内代码、链接、标题、列表、引用和表格单元格都会保留选区两侧未选中的内容。
- **跨段与原子内容**：跨段选区替换按起点格式合并内容；公式、Wiki 链接与脚注按原子整体替换；粘贴换行跟随文档的 LF / CRLF。
- **嵌套格式**：在已有粗体中粘贴粗体文字不再产生嵌套标记。

### 编辑与保存

- 优化新文件首次保存：默认文件名在本地从标题或首行提取，保存、另存为及关闭时保存不再等待 AI 命名请求；保存前同步所见即所得的最新输入。
- 缩进参考线参考 Obsidian，按真实嵌套列表层级显示；源码模式不再因普通正文的前导空格产生跨空行竖线，源码与所见即所得共用样式设置。
- 修复连续普通文本行切回所见即所得时共用一个块的问题：按行建立独立编辑块，保留原有换行与空白；跨行格式、硬换行、列表、引用、表格和代码块保留完整语法结构。
- 修复源码对照中正文与预览逐行错位与定位条覆盖整个段落的问题；点击预览中的对应行可跳回源码。
- “关于 Zeditor”的版本号及本版本更新说明改为读取应用版本与 `CHANGELOG.md` 中的对应版本记录，避免显示过期内容。

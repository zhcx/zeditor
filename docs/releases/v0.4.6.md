# Zeditor v0.4.6

> 发布日期：2026-09-19

## 更新亮点

本版本新增 Mermaid 图表快捷命令、Reveal.js 演示模式和富文本粘贴转换，并集中修复预览交互、代码块转换、演示渲染及编辑器粘贴撤销问题。

## 更新日志

### 图表与演示模式

- 新增 `/gantt`、`/sequence`、`/state`、`/class` 和 `/slide` 斜杠命令，快速插入 Mermaid 图表或演示分页模板。
- 新增「功能 → 演示模式」：按顶层 `---` 拆分幻灯片，支持 YAML frontmatter、代码围栏、Mermaid、KaTeX、代码高亮、暗色主题、键盘翻页和全屏退出。
- 演示模式使用懒加载，Esc 和退出按钮会完整清理 Reveal.js 页面状态；外链交给系统浏览器或独立窗口打开。
- Mermaid 使用 SVG 文字输出，避免安全清洗移除节点标签；异步渲染在关闭演示后不会继续写入页面。

### 富文本粘贴

- 从网页、Word 等来源粘贴 HTML 时，将标题、段落、列表、任务列表、链接、表格、引用、图片、强调和代码转换为 Markdown。
- Monaco EditContext 与 textarea 输入引擎均支持富文本粘贴；纯文本、HTML 源码和没有新增 Markdown 语义的内容继续使用原生粘贴。
- 块级 Markdown 会自动与光标前后的段落分隔，行内 Markdown 保持原位置；程序化粘贴可独立撤销。
- 代码块保护 `<`、`>`、实体、空行及反引号，支持嵌套列表、引用和表格分隔符。

### 预览与编辑体验

- 预览区任务列表复选框现在可直接同步编辑器源码，支持 `-`、`*`、`+`、有序列表、缩进和引用形式；演示模式中的任务列表保持只读。
- 修复任务状态切换方向、同类型嵌套列表内容丢失、HTML 实体重复解码和代码围栏误识别。
- 升级 Mermaid 至 11.17.2、sharp 至 0.35.4，修复发布质量门禁报告的依赖安全问题。
- 演示模式进入后焦点落在浮层，Tab 焦点保持在演示内容内，退出后恢复编辑器焦点。

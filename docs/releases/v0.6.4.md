# Zeditor v0.6.4

> 发布日期：2026-10-17

这是「所见即所得」正式落地、并补齐 macOS 原生体验的版本：新增第四种工作区模式，整篇文档按最终排版渲染、直接在渲染结果上写作；同时恢复 macOS 的原生窗口、系统菜单与系统快捷键，关闭窗口与退出行为回到 macOS 惯例。

## 更新日志

### 新增：所见即所得编辑模式

- 新增第四种工作区模式「所见即所得」：整篇文档按最终排版渲染，直接在渲染结果上编辑，不需要认识 Markdown 标记。原「分屏模式」更名为「源码对照」。
- 首次安装会弹出「选择你的编辑方式」（所见即所得 / 源码对照），选择结果记入 `editor.mode`，之后启动直接进入该模式；随时可在菜单「功能」、活动栏编辑模式弹层、状态栏模式标签或 `Ctrl+Alt+M`（macOS `⌥⌘M`）切换。
- 就地编辑：段落、标题（h1–h6）、引用、有序 / 无序 / 任务列表（含嵌套）、行内格式与链接、表格单元格及围栏代码块；代码支持即时写回和语言选择。
- Markdown 快捷输入与结构编辑：行首 `# ` / `- ` / `1. ` / `> ` / ```` ``` ```` / `---` 即时转块；回车续列表与引用、空块退块、`Tab` / `Shift+Tab` 调层级、`Ctrl+1`–`Ctrl+6` 设标题级别、`Ctrl+0` 还原段落；退格在块首删空块 / 去前缀 / 合并上一段落。
- 行内标记「输入即渲染」：正文里直接敲 `**粗体**`、`*斜体*`、`~~删除线~~`、`` `代码` ``，标记闭合时当场变成对应格式；内容为空、标记未真正闭合或光标停在标记中间时不接管，避免与渲染结果分叉。
- 块级操作：点击块左侧菜单可移动、复制、插入、删除或编辑源码；块源码编辑为就地编辑，带 `Ctrl+Enter` 保存、`Esc` 取消。
- 撤销与重做使用内容级快照栈（连续输入合并为一步），并接管浏览器自带撤销；输入法组合期间不回写、不重渲染。
- 预览与所见即所得共用同一套渲染与增强管线（`utils/markdownPipeline.ts`、`utils/markdownEnhancers.tsx`），两处排版不会漂移。

### 新增：macOS 原生适配

- **原生窗口**：使用 `titleBarStyle: Overlay` + 系统红绿灯，保留原生圆角、阴影、缩放手势与标题栏拖拽；红绿灯按 34px 标题栏居中（实测 `x=20`、`y=18`）。
- **原生菜单栏**：应用 / 文件 / 编辑 / 功能 / 窗口 / 帮助六个菜单由窗口内菜单模型生成，撤销、重做、剪切、复制、粘贴、全选、最小化、缩放、前置全部窗口、关闭窗口、服务、隐藏、退出使用系统预定义项；安装成功后才隐藏窗口内菜单，失败自动回退。
- **系统快捷键**：菜单与提示按 macOS 惯例显示 `⌘` / `⇧` / `⌥` / `⌃`；`Ctrl+S` → `⌘S`、`Ctrl+Shift+S` → `⇧⌘S`、`Ctrl+Y` → `⇧⌘Z`、`F11` → `⌃⌘F`。新增 `⌘,` 打开设置、`⌃⌘F` 切换全屏。
- **关闭与退出**：`⌘W`、红绿灯与菜单「关闭窗口」只隐藏窗口并留在 Dock，点击 Dock 图标恢复；`⌘Q` 与菜单「退出」在未保存守卫确认后退出，窗口隐藏时先恢复再提示。
- **Finder 与 Dock**：双击 `.md` / `.markdown` 由 Apple Event 接收打开，Dock 点击恢复隐藏窗口；`Info.plist` 声明简体中文 / 繁体中文 / 英文，系统「打开 / 保存」面板跟随界面语言。
- **外观细节**：内容字体按平台回落（SF Pro / 苹方）、系统蓝强调色与焦点环、覆盖式滚动条、窗口底色与原生外观跟随主题，消除缩放 / 全屏白底。

### 改进

- 编辑区纵向节奏：按块类型补分级上边距（标题 0.9em、表格 / 代码 / 引用 0.7em、其余 0.45em），分隔线恢复上下留白。
- 表格体验：按单元格内容宽度渲染、合并相邻边框、补上预览同款外框与 108px 单元格最小宽度；宽表格可横向滚动、列宽拖拽不受影响。
- 所见即所得显示校对波浪线：结果绑定校对时的标签与内容快照，文档变化时清除过期标记，高亮不改写 DOM。
- 性能：规范化只重建脏块，普通编辑不再刷新整篇块 DOM；稳定块组件回调、按最近使用淘汰单个 HTML 缓存条目；空段落行号改用已有行索引定位。

### 修复

- 修复段落行高跳变与段间距越写越大：直接承载文本的段落块与渲染出的 `<p>` 使用同一行高（1.84），空段落最小高度同步。
- 块手柄与块首行的行盒中心严格对齐，手柄图标换成几何居中的 SVG，不再受字形基线影响。
- 修复有序列表编辑后起始编号重置为 1、回车续号取第一项序号的问题；子项回车使用最内层文本容器，保留嵌套层级。
- 修复代码块末尾回车和空行被吞掉、Windows CRLF 文档的闭合围栏进入代码正文的问题。
- 修复块尾 `Delete` 无效、方向键不能跨块、切换块时光标被拉回上一个块的问题。
- 修复大纲把列表后的 `---` 误识别为 Setext 标题的问题。
- 修复块手柄隐藏时仍吃掉正文左侧留白点击的问题。
- 修复编辑宿主拦截输入、空文档不可编辑、组合输入结束未写回、回车后光标回到原处的问题。

### 实现说明

- macOS 原生能力位于 `src-tauri/src/main.rs`（`RunEvent::Opened` / `Reopen` / `ExitRequested`）、`src/utils/nativeMenu.ts`、`src/utils/platform.ts`、`src/styles/macos.css`、`src-tauri/tauri.macos.conf.json` 与 `src-tauri/Info.plist`；退出闸门通过 `ExitState` 保证前端守卫确认后才放行。
- Windows / Linux 的窗口内菜单、自绘窗口按钮与快捷键显示保持不变；所有 macOS 样式仅在首帧前写入的 `data-platform="macos"` 下生效。
- 新增 `tests/macosAdaptation.test.ts`（9 项）锁定窗口配置、本地化、平台作用域、快捷键、菜单结构与窗口生命周期。
- 最低系统版本调整为 `12.0`。安装包默认不做代码签名与公证；本地需要临时签名时可设置 `APPLE_SIGNING_IDENTITY="-"` 后打包，正式分发仍需 Apple Developer ID 证书与公证（见 README 的说明）。

### 已知限制

- 多光标仍使用源码模式；图表与块级公式通过块源码的就地编辑修改。
- 引用块末尾的空引用段落在重新渲染后会被 Markdown 规范化掉（Markdown 无法表达真正的末尾空段落）。
- macOS 安装包未做代码签名与公证，首次打开需右键「打开」或到「系统设置 → 隐私与安全性」放行。

# Zeditor v0.4.7

> 发布日期：2026-09-21

本版本聚焦 Markdown 编辑效率：新增文本清理、自动配对与 Tab 跳出，并为代码上下文和编辑器设置提供完整保护。

## 更新亮点

- **文本清理**：通过「格式 → 文本清理」删除行尾空白字符，并将连续空白行压缩为一个；有选区时处理选区，无选区时处理全文，整次操作可撤销。
- **自动配对**：支持 `() [] {}`、英文引号、反引号、中日韩括号和弯引号。
- **Markdown 格式标记**：支持粗体、斜体、行内代码、删除线和链接模板的自动配对。
- **Tab 跳出**：按 Tab 跳过自动插入的闭合字符；空配对按 Backspace 一次删除。
- **代码上下文保护**：围栏代码块和已有内容的行内代码中不执行自动配对、Tab 跳出或空配对删除。
- **编辑器设置**：可在「设置 → 编辑器」中关闭自动配对与 Tab 跳出，桌面端和浏览器设置均会持久保存。

# Zeditor v0.5.2

> 发布日期：2026-09-24

本版本带来两项核心能力：**内联弹窗（Inline Popups）** 与 **GitHub Actions 工作流查看器（Workflow Viewer）**。前者把链接、图片、公式、脚注与 Wiki 链接的编辑收拢到光标旁的原位弹窗里；后者把仓库中的 CI 工作流 YAML 渲染成可交互的依赖图，可直接查看诊断并结构化编辑。

## 更新亮点

### 内联弹窗（Inline Popups）

在源码编辑器中，鼠标点击链接、图片、数学公式、脚注或 Wiki 链接即可在原位弹出编辑窗，无需切换预览或记忆语法。所有弹窗共享统一的键盘交互：**`Enter` 确认、`Esc` 关闭、点击弹窗外部关闭**。

- **链接**：`[文字](地址)` 点击弹出「文字 / URL」两个字段。编辑文字时弹窗自动收起，URL 空则保留为纯文字。
- **图片**：`![替代文本](地址 "标题"){width=420}` 点击弹出「来源 / 替代文本 / 标题」。支持**浏览**本地图片（文件选择器），复制路径、删除；`{width=...}` 尺寸属性原样保留。
- **数学公式**：光标进入 `$…$` 或 `$$…$$` **自动弹出**，LaTeX 编辑区带 **KaTeX 实时预览**与语法错误提示；离开公式自动收起；`Ctrl+Enter` 保存。
- **脚注**：`[^1]` 点击弹出「标记 / 内容」，支持多行编辑（高度自动增高）、**跳转到定义**、删除；定义不存在时确认后自动追加到文末。
- **Wiki 链接**：`[[目标|别名]]` 点击弹出「目标 / 显示文字」。

**快捷操作**

| 操作 | 效果 |
| --- | --- |
| `Ctrl/Cmd + K` | 光标已在链接内时聚焦 URL 字段；否则把选区（或光标处）包成链接——**剪贴板是 URL 时自动填入** |
| `Ctrl/Cmd + 点击` | 直达：网络链接在浏览器打开，脚注跳到定义 |
| `Enter` | 在弹窗输入框中确认修改 |
| `Esc` | 关闭弹窗 |
| 点击弹窗外部 | 关闭弹窗 |

可在「设置 → 编辑器 → 启用内联弹窗」中关闭该功能。

### GitHub Actions 工作流查看器（Workflow Viewer）

- 打开 `.github/workflows/*.yml` 文件，右侧预览区渲染为可交互的 **job 依赖图（DAG）**、触发器与诊断。
- 点击 job / step 查看详情；`GHA-*` 诊断覆盖重复 job、循环依赖、未知引用、`pull_request_target` 安全提示等。
- 支持 Mermaid / SVG 导出。
- Markdown 代码围栏中的工作流同样**内联渲染（只读）**。
- 结构化编辑 job / step / `with` 字段后写回编辑器，**保留注释与缩进**。

### 修复

- 修复在链接、图片等内联结构上直接编辑导致弹窗错位或失效的问题；弹窗随文档滚动与编辑实时跟随，目标结构被改动后自动收起。

## 验证

- 前端测试、ESLint、TypeScript 构建和 Rust 质量检查由 GitHub Actions 在发布前执行。
- 本轮新增测试覆盖：内联目标检测（链接 / 图片 / 公式 / 脚注 / Wiki 链接的区间精确性、转义、代码块忽略、块级公式跨行）与编辑器接线；工作流解析、依赖图、诊断与结构化编辑往返。
- 界面经明暗双主题实机走查：内联弹窗的定位、跟随与键盘交互，工作流查看器的依赖图与编辑回写。
- Windows、macOS 和 Linux 安装包均由同一 `v0.5.2` 标签源码构建。

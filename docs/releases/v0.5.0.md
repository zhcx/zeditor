# Zeditor v0.5.0

> 发布日期：2026-09-23

本版本聚焦编辑器的操作效率：右键菜单按应用场景重组，常用格式与插入动作可直接在光标处完成；浮动工具栏把同类命令收进下拉菜单；表格编辑的多处细节问题一并修复。

## 更新亮点

### 右键菜单（按应用场景重组）

- 六类分组：AI（润色 / 翻译）、编辑与剪贴板（撤销、重做、剪切、复制、复制为、粘贴、粘贴为纯文本、全选）、格式（加粗、斜体、删除线、高亮、下划线、上标、下标、行内代码、清除行内格式）、标题（1 - 6 级）、插入（链接、图片、表格、代码块、引用、分割线）、表格、导出与文件。
- **「表格」子菜单始终可用**：顶部「插入 3 × 3 表格」随时可点；行列增删、对齐、整理与删除在光标位于表格内时启用，否则置灰并给出一行提示。
- 二级菜单统一挂载到窗口层并按触发行的位置定位（左右与上下自适应、越界夹取），修复了子菜单被主菜单裁剪、挤出横向滚动条以及弹出位置错位的问题；指针跨越间隙时延迟收起。
- 打开菜单与点击菜单项都不再抢占焦点：选中的文字保持高亮，格式与剪贴板动作始终作用于原选区。
- 右键位置不在当前选区内时，先把光标移到点击处，表格菜单与格式化动作与所指位置一致。
- 每一行使用独立描边图标（剪切 / 格式 / 标题 / 插入 / 全选等），不再出现多行共用同一个图标或文字符号混排。

### 浮动工具栏

- 同类命令收进下拉菜单（样式 / 标题 / 列表 / 整理 / 插入 / 公式 / 图表），直接按钮只保留加粗、斜体、删除线、撤销、重做与表格，按钮数量由 40 个精简到 13 个。
- 统一为文字标签，不再混用字母、箭头与图标；下拉菜单按触发按钮实时定位，支持 ↑↓ 切换、Enter 执行、Esc 关闭，展开时不会让编辑器丢失选区。

### 表格编辑

- 工具栏表格按钮合并为唯一入口：点击打开尺寸选择器，拖动选择行列，或直接使用「插入 3 × 3 表格」（与 `Ctrl+Shift+T`、功能菜单、斜杠 `/table` 同一套模板）。
- 新增行、新增列改为空白单元格：光标直接落在新单元格里输入，不再写入「内容 / 列 N」占位，与插入表格时的空正文行保持一致。
- 表格选择器改为挂载到 `body`（不再被浮动工具栏的 `transform` 影响），并以「点击到的按钮元素」为锚点，弹出位置准确、越界自动翻转。

### 预览细节

- 表格不再无条件显示横向滚动条：只有表格实际超出可用宽度（或拖动加宽过列）时才启用滚动，窄表格下方不再挂一条空滚动条。
- 当前行指示条改在列表项本体上绘制：竖条落在项目符号（`•` 或编号）左侧，不再错位到文字前。
- 插入图片弹窗去掉「（推荐）」字样，选项标题不再折行、说明文字右对齐，弹窗适当加宽。

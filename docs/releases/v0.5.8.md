# Zeditor v0.5.8

> 发布日期：2026-10-04

Zeditor v0.5.8 改进了日常写作的可读性、操作反馈与文件兼容性，并优化编辑器启动和文件读写。macOS 现在显示 ⌘、⇧、⌥ 快捷键；检查更新会按本机架构选择 Apple Silicon 或 Intel 安装包。

## 更新日志

- **文字编码选择**：支持 UTF-8、UTF-8 BOM、UTF-16 LE/BE（有或没有 BOM）、GBK、GB18030、Big5、Shift-JIS、Windows-1252。状态栏可为文档选择打开、重新读取或保存编码；不确定编码时先询问，不静默猜测。无法表示的字符不会覆盖原文件；云端历史保留原始字节。
- **排版控制**：设置 → 外观可单独调整界面字号（11–20 px）与字间距（0–5 px）；默认字号 13 px、字间距 **0.6 px**。调整即时预览，正文大小独立保存。
- **统一的图标与品牌**：活动栏、菜单、工具栏、文档类型和功能面板采用简洁几何图标；AI 助手沿用原来的双星图标。软件图标换成蓝底白色 Z，并同步更新各平台安装包、启动标识与 favicon。
- **更流畅的启动与编辑**：延迟加载大型编辑器、改进状态订阅、文件读取去重、资源缓存与长文统计；优化了异步导入时的目标文档检查和原子保存。
- **更顺手的文档操作**：`Ctrl/Cmd+P` 搜索打开的文档；标签支持键盘导航、自动滚动和未保存关闭保护；小窗口工具栏自动收纳。
- **macOS 快捷键标识**：菜单、帮助、提示及编辑器右键菜单按当前平台显示快捷键；macOS 使用 ⌘、⇧、⌥。
- **macOS 自动更新架构匹配**：Apple Silicon 版选择 `aarch64.dmg`，Intel 版选择 `x64.dmg`，不会再下载错误架构的安装包。

## 使用说明

- **旧编码文档**：打开后按界面提示选择实际编码；若文本显示不正确，可点击状态栏编码标识并重新读取。
- **调整排版**：进入设置 → 外观，拖动「界面字号」与「字间距」滑块；保存后偏好会在后续启动时恢复。
- **macOS 快捷键**：帮助 → 快捷键说明查看当前平台标识。⌘ 对应 Command，⇧ 对应 Shift，⌥ 对应 Option。

# Zeditor v0.6.2

> 发布日期：2026-10-07

这是一个修复版本：修正「点击编辑器后预览把对应内容顶到窗格最上方」的同步滚动回归，并修复长行文字溢出编辑框的问题。

## 更新日志

### 修复

- **预览跳转恢复镜像对齐**：点击编辑器任意位置时，对应内容会出现在预览窗格的**同一相对位置**——点击处位于编辑器视口 30% 高度的，对应内容就落在预览视口约 30% 高度。此前用固定偏移把目标一律钉在离顶部 88px 处，看起来总是「被顶到最上方」。预览 → 编辑器方向同样按镜像对齐处理，仅保留很小的呼吸位避免贴合上沿。
- **长行不再溢出编辑框**：编辑器折行改用**基于真实字形测量**的策略。此前按缓存的字符宽度估算折行位置、未计入字间距（本应用字间距默认 0.6px），长行（如超长表格行）的渲染宽度大于折行宽度而溢出窗格；又因为横向滚动条按设计隐藏，尾部既看不到也滚不到。现在折行宽度与实际渲染宽度一致。
- **文档站版本号自动跟随**：使用文档导航栏的版本号改为构建时读取应用 `package.json`，此前它被硬编码，历次发版容易漏改（曾停留在 v0.5.9）。

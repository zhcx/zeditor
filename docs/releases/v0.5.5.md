# Zeditor v0.5.5

> 发布日期：2026-09-29

本版本带来三项更新：**MCP 集成**——让 Claude Desktop、Claude Code、Codex CLI、Gemini CLI 等 AI 助手通过 MCP 协议直接读写你的文档；**设置界面统一与美化**——把设置面板中的下拉菜单、按钮、输入框统一为一套简约现代、随明暗主题自适应的控件规范；以及**资源管理器工作区分组标题**。

## 更新亮点

### 1. MCP 集成：让 AI 助手直接读写你的文档

- 内置 **MCP 服务器**：Zeditor 随安装包附带 `zeditor_mcp_server` 二进制，作为 stdio ↔ WebSocket 桥接，让任何 MCP 兼容客户端把 Zeditor 当作可读写的文档工作区。
- **11 个工具**：`session_get_state`、`workspace_new` / `workspace_open` / `workspace_save` / `workspace_save_as` / `workspace_close` / `workspace_switch_tab`、`document_read` / `document_write`、`selection_get` / `selection_set`；`document_write` 支持 `expected_revision` 乐观并发（版本过期返回 `STALE` 错误信封，避免覆盖你手头的修改）。
- **一键配置**：设置 → 集成 中可为 Claude Desktop、Claude Code、Codex CLI、Gemini CLI 一键写入 MCP 配置，并显示每个客户端的安装状态（已安装 / 路径不匹配 / 未安装）。
- **安全边界**：桥接仅监听本机（127.0.0.1）并使用随机令牌认证；文件操作被限制在已打开的工作区根与文档目录内，越界路径会被 `INVALID_PATH` 拒绝。
- **可审阅的 AI 修改**：默认情况下，AI 的写入会以「AI 修改建议」内联差异呈现，由你接受或拒绝；仅在显式开启「自动批准编辑」后才会直接落盘。
- **状态栏指示器**：灰 = 未运行，绿 = 运行中，脉冲绿 = 有 AI 助手连接；点击可直达设置。

### 2. 设置界面统一与美化（简约现代 · 明暗自适应）

- **下拉菜单全部重做**：设置面板中 14 个原生 `<select>` 替换为统一的自绘下拉——浮层跟随主题、选项带品牌色徽标与说明、选中高亮 + 勾选、键盘导航（↑↓ / Enter / Esc）、点击外部关闭；选项超过 8 项时自动出现搜索框。
- **AI 服务商下拉**：13 个内置服务商带品牌色徽标与默认模型说明，支持搜索快速定位。
- **按钮统一样式**：建立主按钮 / 次按钮 / 幽灵图标按钮三级体系，规范高度、圆角、内边距、悬停加深、按下位移与禁用态；修正此前多轮规则叠加造成的高度（34/36px）与圆角（7/8px）不一致。
- **输入框与下拉统一**：文本 / 数字 / 密码 / URL 输入框与下拉触发器统一为 42px 高、8px 圆角、浅浮起背景；聚焦时显示强调色描边与淡色光环。
- **明暗主题零色差**：以上控件全部基于主题 CSS 变量，深浅主题自动切换；WebDAV / S3 云同步按钮、字体选择器（含下拉浮层）一并纳入统一规范。

### 3. 资源管理器：工作区分组标题

- 「工作区」文件夹区域新增与其他分区一致的分类标题（折叠箭头 + 名称 + 文件夹数量），可整体折叠 / 展开。
- 根文件夹标题缩进一级，与分组标题形成清晰的主次层级；未打开文件夹时直接展示打开引导。

## 新功能使用指南

### 一、MCP 集成：让 AI 助手直接读写文档

MCP（Model Context Protocol）是一个开放协议，让 AI 助手能够调用外部工具。Zeditor 内置 MCP 服务器后，Claude Desktop、Claude Code、Codex CLI、Gemini CLI 等客户端即可直接读取当前文档、修改内容、切换标签页与保存文件。

> 完整的客户端配置示例与工具参数说明见 [`docs/mcp-support.md`](../../docs/mcp-support.md)。

#### 1. 前置条件

- 使用 **Zeditor 桌面版**（MCP 桥接依赖本地进程与文件系统权限，纯 Web 版不可用）。
- 已安装至少一个 MCP 兼容客户端：Claude Desktop、Claude Code、Codex CLI 或 Gemini CLI。

#### 2. 在 Zeditor 中启用 MCP

1. 打开 **设置 → 集成**。
2. 打开 **「启用 MCP 服务器」** 开关。
3. 按需开启以下选项：
   - **启动时自动运行**：Zeditor 打开时自动启动桥接（仅监听本机，带随机令牌认证）。
   - **自动批准编辑**：AI 的修改直接应用，不再弹出「AI 修改建议」审阅。**仅在信任该助手时才开启**。
4. 观察「桥接状态」：点击 **启动桥接 / 停止桥接** 可手动控制；端口仅监听本机回环地址。

#### 3. 一键配置 AI 助手

在 **设置 → 集成 → AI 助手配置** 中，对你使用的客户端点击一键安装：

| 客户端 | 说明 |
| --- | --- |
| Claude Desktop | 写入 `claude_desktop_config.json` 的 `mcpServers` 配置 |
| Claude Code | 写入 Claude Code 的 MCP 配置 |
| Codex CLI | 写入 Codex 的 MCP 配置 |
| Gemini CLI | 写入 Gemini CLI 的 MCP 配置 |

安装后状态列会显示 **✓ 已安装**；若检测到路径不匹配则显示 **⚠ 路径不匹配**，重新点击安装即可刷新为当前路径。

> ⚠️ **配置写入后必须完全退出并重启对应的 AI 助手**，新的 MCP 服务器才会被加载。

#### 4. 开始使用

重启 AI 助手后，它会自动发现 Zeditor 提供的工具。你可以直接对助手说：

- 「读取我当前在 Zeditor 里打开的文档并总结要点」
- 「把选中的段落改得更简洁，然后保存」
- 「在当前文档末尾追加一段结论」
- 「列出我打开的所有标签页」/「切换到 *xxx* 文档」

助手会通过 MCP 工具读取/写入文档；若未开启自动批准，你会在编辑器中看到「AI 修改建议」差异，可逐条接受或拒绝。

#### 5. 可用工具一览

| 工具 | 作用 |
| --- | --- |
| `session_get_state` | 读取当前会话状态（打开的标签页、活动文档等） |
| `workspace_new` | 新建文档 |
| `workspace_open` | 打开工作区内的文件 |
| `workspace_save` | 保存当前文档 |
| `workspace_save_as` | 另存为（限定在允许的目录范围内） |
| `workspace_close` | 关闭标签页 |
| `workspace_switch_tab` | 切换活动标签页 |
| `document_read` | 读取文档内容（含修订号） |
| `document_write` | 写入文档内容，支持 `expected_revision` 乐观并发 |
| `selection_get` | 获取当前选区 |
| `selection_set` | 设置当前选区 |

#### 6. 安全与边界

- 桥接进程仅监听 **127.0.0.1** 并使用**随机令牌**认证，外部网络无法直接连接。
- 所有文件操作被限制在**已打开的工作区根目录与文档所在目录**内；越界路径返回 `INVALID_PATH`。
- 默认不自动落盘：AI 修改以差异审阅形式提交给你确认。
- 关掉「启用 MCP 服务器」或点击「停止桥接」即可立即断开所有 AI 接入。

#### 7. 故障排查

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 助手看不到 Zeditor 工具 | 配置后未重启助手 | 完全退出并重启对应的 AI 助手 |
| 状态显示「⚠ 路径不匹配」 | Zeditor 更新后安装包路径变化 | 在设置 → 集成 重新点击一键安装 |
| 状态栏 MCP 指示为灰色 | 桥接未运行 | 在设置 → 集成 点击「启动桥接」，或开启「启动时自动运行」 |
| 写入被拒绝（`STALE`） | 文档在 AI 读取后被你自己修改 | 让助手重新读取文档后再写入 |
| 写入被拒绝（`INVALID_PATH`） | 目标文件不在已打开的工作区 / 文档目录内 | 先在 Zeditor 中打开对应文件夹 |

### 二、设置界面

设置面板的下拉、按钮、输入框已统一为一套简约现代风格，并随明暗主题自动适配：

- **下拉菜单**：点击后展开主题化浮层，选项带徽标与说明，支持搜索与键盘导航；设置项如「AI 服务商」「主题」「图床服务」「搜索服务」等均为同一套交互。
- **按钮**：主按钮（保存、获取模型列表）为强调色实心；次按钮（取消、读取字体、检测 Agent）为描边样式；图标按钮（密钥显隐）为幽灵样式。
- **输入框**：所有输入框与下拉触发器高度、圆角、聚焦光环一致，浅色 / 深色主题下观感统一。

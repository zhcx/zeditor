# Zeditor v0.5.9

> 发布日期：2026-10-05

本版本更新了 Windows Markdown 文件关联图标，并修复 S3 云同步重复添加远端根目录的问题。

## 更新日志

- **Windows Markdown 图标**：`.md` 与 `.markdown` 文件安装关联后，系统现在显示新版蓝底白色 Md 与 Z 图标。使用已安装版本的用户需通过 v0.5.9 安装包更新文件关联图标。
- **S3 根目录去重**：同步管理器已将根目录包含在对象路径中，S3 客户端不再重复拼接。例如根目录 `/Zeditor` 的新对象键为 `Zeditor/工作区/文档.md`。
- **保留旧备份**：更新不会删除之前存放在 `Zeditor/Zeditor/` 下的对象；新同步使用单层 `Zeditor/` 路径。旧备份仍保存在云端原位置。

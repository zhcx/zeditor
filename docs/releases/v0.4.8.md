# Zeditor v0.4.8

> 发布日期：2026-09-22

本版本为文档引入本地媒体能力：视频与音频可以直接引用同目录素材，导入即复制到 `.assets` 目录，预览区渲染原生播放器。

## 更新亮点

- **本地媒体语法**：新增 `@[video](...)` 与 `@[audio](...)`，路径可指向本地文件、mp4 / mp3 直链，或 B站、YouTube、Vimeo 平台链接。
- **插入媒体**：工具栏「插入媒体」可选择本地视频 / 音频，或粘贴在线链接；选择本地文件时会复制到文档同级的 `.assets` 目录，避免文档移动后素材失效。
- **拖拽导入**：视频 / 音频文件拖入窗口即导入并插入媒体语法，不再当作文档打开。
- **原生播放器**：预览为本地媒体渲染播放器，支持进度、音量与全屏，并解析 `title`、`poster` 属性；文件缺失时显示提示卡片。
- **图片语法兼容**：`![](demo.mp4)` 等媒体文件会被自动识别并渲染为播放器。
- **语法指南与命令**：帮助文档新增「音频」条目并补充本地视频写法；斜杠命令新增 `/audio`。

## 安全与实现说明

- 本地媒体播放依赖 Tauri `assetProtocol`（`protocol-asset` 特性）与 CSP `media-src` 中的 `asset:`、`http://asset.localhost`，仅用于读取用户文档同目录的媒体素材。
- 导入的本地素材写入文档同级 `.assets` 目录，不上传任何服务器。

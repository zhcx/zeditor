# Zeditor 代码检查、修复与性能优化

日期：2026-10-04

本轮检查覆盖 React/Zustand 状态与编辑流程、Monaco 集成、Markdown 预览与大纲、文件打开和保存、图片与媒体导入、桌面设置序列化，并结合现有 AI/Agent、MCP、导出、转换器和云备份的代码及测试检查回归风险。按可复现的问题修改，保留现有架构和功能入口。

## 已完成的修改

| 范围 | 问题与修改 |
| --- | --- |
| 启动加载 | 原来的 Monaco 延迟加载模块未被编辑器使用，实际静态导入把整个内核放进入口。现在通过 React.lazy 单独加载 Editor，并提供加载提示；未保存确认对话框也按需加载。 |
| 状态订阅 | App 和多个面板订阅整个 store，输入、进度和状态提示容易触发无关组件更新。改为选择所需字段，并使用 useShallow 比较。 |
| 最近文件 | 资源管理器的历史写入 effect 依赖 tabs，每次输入都会写入磁盘和 localStorage。改为依赖当前标签、路径和标题；浏览器模式不再调用桌面历史命令。 |
| 字数统计 | 原实现用 Array.from 为整篇文章创建字符数组。改为扫描 UTF-16 代理对计数，保留中文、英文单词、Emoji 和未配对代理项的统计语义。 |
| 关闭保护 | 资源管理器直接 closeTab，会丢弃未保存修改。抽取共用 useTabClose，使其和标签栏采用同一保存/放弃/取消流程；保存期间取消或继续编辑不会关闭文档。 |
| 文件打开 | 已打开标签先读取磁盘，离线文件无法重新选中；慢读取会抢走后打开文件的焦点。现在先复用标签，合并同路径的在途读取，旧请求只添加后台标签；读取失败显示原因并向调用方抛错。文档转换也遵守最近一次选择。 |
| 图片和媒体导入 | 异步导入结束时读取当前标签，切换文档可能插入到另一篇文章。现在记录原标签和路径，后台文档追加引用，原标签关闭或路径改变时拒绝插入；剪贴板异步读取/上传也检查文档变化。 |
| 媒体路径缓存 | 缓存没有容量和有效期，也不合并正在执行的请求。现在最多保留 512 项，成功结果缓存 30 秒、缺失结果缓存 2 秒，并合并并发解析。失效前的旧结果不能重新污染缓存；超出缓存容量的一次批量解析仍完整返回。缓存到期后在下一次预览解析时重新探测。 |
| 桌面设置 | Rust 缺少 workflow、editor.inline_popups 和 ai.proofread_with_ai 字段，保存后会丢失开关值。补齐序列化字段及旧配置默认值。 |
| 文档保存 | 直接写原文件会先截断内容。现在先写同目录的唯一临时文件并同步到磁盘，再替换目标；失败清理临时文件并保留原文件，保留符号链接目标语义，并拒绝覆盖只读文件。 |
| 大纲 | 带有内容的围栏行错误地关闭代码块，导致代码中的标题进入大纲。修正围栏开闭判断，并让独立大纲组件复用已有解析函数。 |

## 测量结果

| 指标 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 生产构建入口 JavaScript，未 gzip | 4,837.52 kB | 约 944 kB |
| 连续 20 次编辑期间的历史记录写入 | 40 次 | 0 次 |
| 210 万 UTF-16 单位混合文本的字数统计中位耗时，本机测量 | 约 61 ms | 约 39 ms |

入口包缩小约 80%，编辑器内核作为独立异步包加载。入口体积减少与总依赖体积、总启动耗时是不同指标。统计时间会随机器负载变化，基准脚本同时运行优化前算法和当前算法进行比较，不设置易波动的时间阈值。

## 验证与复现

在项目根目录运行：

```powershell
npm test
npm run lint
npm run build
node scripts/benchmark-text-statistics.mjs
```

在 src-tauri 目录运行：

```powershell
cargo test --bins
cargo fmt --check
```

浏览器验证使用独立的无头会话，启动开发服务器后运行：

```powershell
npm run dev -- --host 127.0.0.1 --port 1425 --strictPort
node scripts/verify-editor-performance.mjs
```

浏览器脚本需要 agent-browser；Windows 默认使用系统 Edge，也可通过 AGENT_BROWSER_BIN 指定 CLI 路径。它检查大文档预览最终同步、输入期间无历史写入、资源管理器关闭保护、任务勾选写回、标签切换后的撤销/重做以及三种编辑/阅读模式切换。

新增回归测试直接加载实际 store/service，模拟桌面 IPC 的延迟和错误，覆盖导入期间切换/关闭文档、读取竞争、重复读取、媒体缓存失效与大批量返回。Rust 新增设置往返和原子保存测试。

本轮在 Windows 上验证前端构建、Rust 测试和 Edge 浏览器交互。付费 AI API、真实远程云备份、外部转换模块下载安装、安装包签名以及 macOS/Linux 的实际桌面运行未作端到端验证；现有测试覆盖其相关逻辑，3 项需要本地 CLI/代理环境的 Rust 集成测试继续保持忽略。

最终检查结果（包含后续编码、字体与图标改进）：前端 430 项测试通过；Rust 171 项测试通过、3 项忽略；ESLint、TypeScript/Vite 生产构建、Rust 格式检查和浏览器交互验证通过。新功能的操作入口与验证见[补充记录](encoding-typography-icons-2026-10-04.md)。

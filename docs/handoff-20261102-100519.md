### 已实现的能力与关键约定

1. **中文排版**：工具栏「整理 → 中文排版」；四项规则（中英文/数字间距、中文标点、全角字母数字转半角、中文引号），选区/全文处理，修改前后对照，确认后一次可撤销编辑。保护判定基于完整原文，预览应用前核验标签、控制器和内容是否仍一致。弹窗挂在 App 层，避免浮动工具栏卸载导致弹窗消失。另修复了折叠工具栏子菜单在 click 前被父菜单关闭的问题。
2. **大文档降级**：新增临时工作区模式 `source`，真正仅挂载 Monaco，不渲染右侧预览。读取内容后、创建视图前进行快速估算：文件大小 ≥ 512 KiB、估算块数 ≥ 1200、估算表格单元格 ≥ 2000，任一命中即推荐轻量模式。阈值为启发式，不是性能保证。优先使用磁盘 `fileVersion.size`，无文件时估算 UTF-8 字节数。打开、转换、恢复草稿、指定编码重读与磁盘重载接入评估。
3. **手动切换**：每个标签的 `performance` 保存评估和 `lightweight` 开关；提示条可以恢复默认视图/重新启用轻量模式。自动切换不改写 `settings.editor.mode`（仍只有 `split` / `wysiwyg`）。模式状态、活动栏、首次选择、搜索入口和 Esc 行为已兼容 `source`。
4. **共享编辑历史**：`documentHistory` 按标签持有共享 `UndoStack`，源码和所见即所得共同使用；源码键盘、工具栏、右键菜单和应用菜单接入共享历史。macOS「编辑」菜单的撤销/重做改为应用派发，其他文本输入保留原生行为。每栈最多 200 个快照，累计约 8 Mi UTF-16 字符，至少保留最近一个大快照。关闭标签释放；磁盘重读建立新基线。
5. **外部修改与安全**：`setContent` / `updateTabContent` 增加可选 `origin: 'editor' | 'external'`，默认 external。编辑器回写显式传 editor；外部更新先提交挂起输入、同步建立撤销点，编辑视图同步时避免重复记录。MCP 读取活动文档前提交挂起输入。撤销/重做在控制器或正文尚未同步时拒绝覆盖较新内容。
6. **位置恢复**：`editorViewMemory` 按标签和编辑表面保存选区/滚动位置；显式跨模式切换跟随光标，标签切换恢复该表面上次阅读位置。Monaco 原有 `documentViewStates` 继续使用。控制器新增可选 `tabId`，避免快速切换时把旧标签位置记到新标签。

先补失败回归再修复以下审核发现；完成后再考虑原建议中的第四项「持久化本地版本历史」。不要将当前会话内编辑历史误认为已实现持久化版本历史。

### 1. P1：引用容器内的缩进代码未被保护

- 位置：`src/utils/chineseTypography.ts:56`。
- 输入：`>     const 中文ABC = "中文DEF";`。
- 实际输出：`>     const 中文 ABC = “中文 DEF”;`。
- 使用 MarkdownIt 已确认它是有效的 blockquote → code_block，当前保护仅检查物理行首四空格/Tab，漏掉容器内部缩进。
- 后果：破坏代码标识符及字符串语法。需要识别引用、列表等容器内代码，而不是仅给普通行加正则特例。

### 2. P1：多行 HTML 图片标签的属性会被改坏

- 位置：`src/utils/chineseTypography.ts:85`。
- 输入：`<img\n  src=".assets/图片ABC.png"\n  alt="图片ABC">`（`\n` 表示真实换行）。
- 实际输出中的 src 变为 `src=“.assets/图片 ABC.png”`，alt 引号也被转换。
- 原因：通用标签匹配使用 `<[^>\r\n]*>`，不能保护合法的多行标签；专用 HTML 分支未包含 img。
- 后果：图片路径和 HTML 属性语法损坏。需整体保护跨行标签及其属性，并测试其他媒体标签。

### 3. P2：返回源码标签后第一次撤销的光标跳到文首

- 位置：`src/components/Editor/Editor.tsx:1397` 附近；首次挂载也有类似初始化，应一并检查。
- 复现：源码文稿 `abcdef`，光标放在偏移 4 → 切换别的标签 → 回来 → 输入 X → 撤销。
- 实际：正文恢复 `abcdef`，但选区变为 `{from:0,to:0}`，而不是偏移 4。
- 原因：激活标签时 `historyCaret = 0`，恢复视图期间 `switchingModel` 为 true，光标回调被跳过；第一次输入所保存的历史光标仍为 0。
- 修复方向：恢复原生视图/跨模式选区后、允许编辑前，同步历史光标。

### 4. P2：所见即所得的 Windows Ctrl+Y 无法可靠重做

- 位置：`src/components/Wysiwyg/WysiwygEditor.tsx:645`。
- 复现：所见即所得打开 `abc`，通过控制器追加 X，Ctrl+Z 得到 `abc`，Ctrl+Y 仍为 `abc`，Ctrl+Shift+Z 才恢复 `abcX`。
- 原因：只显式接管 Z / Shift+Z；浏览器没有原生可重做项时，Ctrl+Y 不一定产生 `beforeinput(historyRedo)`。
- 需显式接管 Ctrl+Y，覆盖可视化正文及代码编辑区域。原有回归只测试了可视模式 Shift+Z 和源码模式 Ctrl+Y，漏掉此组合。

### 5. P2：未闭合链接扫描为平方级，阻塞排版预览

- 位置：`src/utils/chineseTypography.ts:100`–106。
- 输入：`'[中文ABC\n'.repeat(16000)`。
- 本机实测：112000 字符约 3060 ms；1000/2000/4000 行分别约 29/68/205 ms（受运行负载影响，不是正式基准）。
- 原因：每一行的未闭合 `[` 都扫描到全文末尾，失败后仅跳过当前行，后面重复扫描剩余全文。
- `ChineseTypographyDialog` 在同步预览计算中调用该函数，切换规则也会重复执行。
- 修复方向：单遍或有界解析，避免已扫描区域反复扫描；保留合法跨行链接支持，并增加输入规模递增的验证。

## 1. 安装与启动

### 1.1 下载安装包

从 [GitHub Releases](https://github.com/zhcx/zeditor/releases) 页面下载对应平台的安装包：

| 操作系统 | 推荐安装包 | 适用场景 |
| --- | --- | --- |
| Windows x86_64（Win10 1809+） | NSIS `.exe` | 大多数用户，按向导安装 |
| Windows x86_64 | MSI | 企业部署、静默安装 |
| macOS Apple Silicon（macOS 12+） | DMG | M1/M2/M3/M4 芯片 |
| macOS Intel（macOS 12+） | DMG | Intel 芯片 Mac |
| Ubuntu / Debian | DEB | Ubuntu 20.04+、Debian 11+、Mint 等 |
| Fedora / RHEL / openSUSE | RPM | RPM 系发行版 |
| 通用 Linux | AppImage | 免安装，`chmod +x` 后直接运行 |

> Windows 安装包可能触发 SmartScreen 警告（尚未代码签名），点击「更多信息 → 仍要运行」即可。

### 1.2 本地构建（开发者）

```bash
git clone https://github.com/zhcx/zeditor.git
cd zeditor
npm install
npm run tauri dev    # 开发模式
npm run tauri build  # 构建发布版
```

环境要求：Node.js ≥ 22.6、Rust ≥ 1.85。

## 2. 界面总览

启动后界面自上而下、自左而右依次为：

- **菜单栏**：只有三个菜单——**Zeditor**（应用菜单）、**文件**、**功能**。编辑与视图类功能统一收在「功能」菜单中。
- **活动栏（最左竖条）**：切换侧边栏的「资源管理器 / 搜索当前文档」两个视图，以及「沉浸模式」按钮。
- **侧边栏**：资源管理器（打开的编辑器、工作区、大纲、近期记录、时间线五个可折叠分组）或「搜索当前文档」查找替换面板。
- **标签栏**：多标签页管理，`+` 新建，双击空白处新建。
- **工具栏**：文字标签按钮分三组（格式 / 编辑 / 插入），空间不足时溢出按钮收进「•••」菜单。
- **编辑器 + 预览**：默认左右分屏，可拖动中间分隔条调整宽度，双向同步滚动。
- **状态栏**：显示保存状态、上传进度、MCP 桥接状态（灰=未运行、绿=等待连接、脉冲绿=AI 助手已连接）与云同步状态。

主题切换：**功能 → 主题**（12 套主题，6 浅色 + 6 深色，当前主题带 ✓）。也可以在 **设置 → 外观** 中选择主题或「跟随系统」；活动栏的明暗按钮可在浅色 / 深色默认主题间快速对切。`F11` 可切换全屏。

## 3. 文件与工作区管理

### 3.1 基本文件操作（文件菜单）

| 操作 | 快捷键 | 说明 |
| --- | --- | --- |
| 新建 | ?+N / Ctrl+N | 新建空白标签页 |
| 打开 | ?+O / Ctrl+O | 文件对话框，支持多选；可打开 Markdown、TXT 等文本，也可直接选择 DOCX/PDF 等可转换文档 |
| 导入并转换文档… | — | 选择 DOC/DOCX/PPT/PDF 等文件，转换为 Markdown 后在新标签页打开 |
| 最近的文件夹 | — | 子菜单，最多 10 条，含「清除最近文件夹」 |
| 保存 | ?+S / Ctrl+S | 已有路径直接保存；未命名文档走「另存为」 |
| 另存为 | ?+?+S / Ctrl+Shift+S | 另存为 `.md`；未命名文档且已启用 AI 时，会先请求 AI 建议文件名 |

**自动保存**：默认每 30000ms 自动保存一次（仅对已有路径且已修改的标签生效），可在 **设置 → 编辑器 → 自动保存间隔** 调整。

**拖拽打开**：把文件或文件夹直接拖到窗口即可打开——文件夹会加入工作区，图片会复制到 `.assets` 并插入，音视频走媒体导入，其余文档按可转换类型处理。

### 3.2 资源管理器侧边栏

侧边栏自上而下五个分组（均可折叠）：

1. **打开的编辑器**：列出所有标签页，未保存的显示圆点，点 `×` 可直接关闭。
2. **工作区**：支持**多根工作区**——打开文件夹时可以一次多选，也可以反复点击「打开文件夹」继续追加。每个根目录行有「关闭文件夹」按钮（只从工作区移除，不删磁盘内容）。重启应用后自动恢复上次的工作区。
3. **大纲**：按当前文档 `#`~`######` 标题自动生成，点击跳转到编辑器对应行。
4. **近期记录**：最近打开的文件与文件夹，保留 50 条、按「设置 → 资源管理器 → 历史记录保留天数」（默认 30 天）过滤。
5. **时间线**：当前文档的**本地版本历史**。悬停可看每条记录的时间和操作；点击打开「历史版本」对话框，含**版本预览**与**与当前对比**（逐行 diff）两个页签；可「恢复此版本」「删除记录」。

工具栏按钮：新建文件、打开文件、打开文件夹、展开所有文件夹、折叠所有文件夹。文件树自动轮询刷新（默认 5 秒，可关闭），点击文件夹懒加载子目录。

**点击非 Markdown 文档（docx/pdf 等）会直接触发 AnyDoc 转换为 Markdown。**

### 3.3 文件/文件夹右键菜单

- **文件**：打开文件、新建文件夹（同级）、复制、剪切、复制路径、在资源管理器中打开、重命名、删除。
- **文件夹**：展开/折叠、新建文件、新建文件夹、复制、剪切、粘贴、复制路径、在资源管理器中打开、重命名、刷新、删除。
- **工作区根目录**：额外有「关闭文件夹 / 关闭所有文件夹」。
- 删除带确认对话框，删除文件会联动关闭相关标签页。新建与重命名都是**内联输入框**（Enter 确认、Esc 取消）。

### 3.4 文档文字编码

点击状态栏的文字编码名称，可选择文档下次保存时使用的编码，或用指定编码重新读取已有文件。支持 UTF-8、UTF-8 BOM、UTF-16 LE/BE（含与不含 BOM）、GBK、GB18030、Big5、Shift-JIS 与 Windows-1252。若无法自动识别编码，可选择文件实际编码后打开；文档有未保存修改时不能重新读取。

### 3.5 搜索与替换

**侧边栏「搜索当前文档」**（活动栏搜索按钮，仅桌面版）：只作用于**当前正在编辑的正文**。

- 输入关键词即出命中列表（行号 + 整行文本），点击定位；`Enter` / `Shift+Enter` 或头部 ↑ / ↓ 在命中间循环。
- `替换` 替换当前命中，`全部替换` 替换全部（带确认）。
- 选项：区分大小写、正则；正则替换支持 `$1` 分组引用。
- **未保存的修改也能搜到**；替换保留撤销历史，一次 `Ctrl+Z` 即可回退。

**顶部统一搜索栏**（`Ctrl+P` 或点击标题栏搜索框）：展开后**输入框就在标题栏那一栏**，下方为结果列表。空输入时先列出**前 5 条快捷命令**（新建文件、搜索当前文档、检查链接、AI 指令面板、演示模式、分屏 / 沉浸阅读 / 沉浸写作、导出为 HTML / Word、设置；右侧显示快捷键）与**近期文件**（与侧边栏「近期记录」同一份数据）；末尾「更多命令…」或直接输入 `>` 可进入命令模式，按名称筛选全部命令。输入关键词后一次可分四组搜索——已打开的文档、当前文档正文命中、工作区文件名、工作区文件内容；`↑` / `↓` 选择、`Enter` 打开（命令则直接执行）、`Esc` 关闭。已打开文档正文与工作区文件名即时出结果；文件内容检索受 1500 文件 / 2 秒预算约束，超出会提示「结果已截断」。点「高级选项」可设置区分大小写、正则、文件类型筛选与忽略目录（默认忽略 `.git`、`node_modules`、`target`、`dist`、`.idea`、`.vscode`）。

## 4. 标签页管理

- **新建**：标签栏右侧 `+`、**双击标签栏空白处**、文件菜单「新建」。
- **切换**：点击标签。
- **关闭**：标签上的 `×`，或**双击标签本身**（注意：双击标签是关闭，不是重命名）。
- **未保存保护**：有未保存修改的标签关闭时弹窗「保存 / 不保存 / 取消」；标题后显示 `●` 修改标记。
- 打开已打开的文件会复用既有标签；新文件优先复用「无路径且未修改」的空白标签。

## 5. 编辑功能

### 5.1 工具栏

工具栏按钮全部为文字标签，分三组；选中文本后会出现**选区浮动工具栏**（在「设置 → 编辑器 → 固定显示编辑快捷栏」开启后常驻固定，关闭时仅选中文字浮现）。

| 分组 | 按钮 | 作用 |
| --- | --- | --- |
| 格式 | 加粗 / 斜体 / 删除线 | 包裹 `**…**`、`*…*`、`~~…~~` |
| 格式 | 样式 ▸ | 高亮 `==…==`、下划线 `<u>`、上标 `<sup>`、下标 `<sub>` |
| 格式 | 标题 ▸ | 一至六级标题 |
| 格式 | 列表 ▸ | 无序 / 有序 / 任务列表、增加缩进 |
| 编辑 | 撤销 / 重做 | Monaco 撤销重做 |
| 编辑 | 整理 ▸ | 减少缩进、清除行内格式、**检查并格式化 Markdown**（弹窗预览问题清单后应用） |
| 插入 | 表格 | 打开网格拖选器选择行列插入 |
| 插入 | 插入 ▸ | 链接、图片、视频/音频、Emoji、代码块、引用、分割线、目录 `[TOC]`、折叠内容 `<details>`、注释、分页符 |
| 插入 | 公式 ▸ | 行内公式、公式块、脚注 |
| 插入 | 图表 ▸ | Mermaid 流程图 / 时序图 / 甘特图模板、Markmap 思维导图模板 |

### 5.2 智能符号配对与 Tab 导航

（设置 → 编辑器 →「启用自动配对与 Tab 跳出」，默认开启）

- 输入括号/引号自动补对，支持中日韩括号 `「」『』（）【】《》〈〉` 与弯引号；输入 `[` 自动补成 `[]()`。
- **Tab 键穿梭规则**（优先级从高到低）：
  1. `(文字|)` → 跳过闭合括号；`"文字|"` → 跳出引号；
  2. `**加粗|**`、`__`、`~~`、`==`、`*`、`_`、`^` → 跳出行内格式标记；
  3. `[文字|](链接)` → 先进入链接字段，再 Tab 跳出。
- 嵌套时每次只跳出一层；多光标各自独立；**围栏代码块与行内代码内自动停用**；Backspace 可删除空符号对。

### 5.3 表格编辑

- **插入**：工具栏「表格」（网格拖选行列）、`Ctrl+Shift+T`（默认 3×3）、斜杠命令 `/table`、右键菜单「表格 → 插入表格」。
- **浮动工具栏**：光标进入表格即出现，包含——插入行（↑/↓）、删除行、插入列（←/→）、删除列、左/中/右对齐（当前列高亮）、整理表格格式（按列宽补齐空格）、删除整张表格。
- **键盘操作**：Tab / Shift+Tab 在单元格间跳转（末行末格 Tab 自动新增一行）；Enter 在当前行下方新增一行；方向键移动。
- 「功能 → 表格操作」子菜单提供同样的 11 项行列与对齐操作。

### 5.4 内联弹窗

（设置 → 编辑器 →「启用内联弹窗」，默认开启）

在编辑器中**点击**链接 / 图片 / 公式 / 脚注 / Wiki 链接，会原位弹出编辑小窗：

- **链接**：修改 URL、打开、复制、移除链接。
- **图片**：浏览本地替换、复制、删除，尺寸属性原样保留。
- **公式**：带 KaTeX 实时预览，随光标自动开合。
- **脚注**：跳转到定义、删除；无定义时确认会自动在文末创建定义。
- Enter 确认、Esc 关闭。**Ctrl+点击 = 直达**（链接用系统浏览器打开、脚注跳到定义）。`Ctrl+K` 创建/编辑链接：剪贴板里是 URL 时自动填入。

### 5.5 富文本粘贴

从网页、Word 等复制的富文本（HTML），粘贴时自动转换为 Markdown 插入，保留标题、列表、链接等语义。粘贴截图/图片文件的处理见[第 7 章](#7-图片视频与音频)。

### 5.6 编辑器右键菜单

右键会将光标移到点击处，菜单包含：**AI 润色 / AI 翻译**（需选区）、撤销/重做、剪切/复制/粘贴、**复制为 ▸**（HTML / 纯文本）、粘贴为纯文本、全选、**格式 ▸**（加粗/斜体/删除线/高亮/下划线/上标/下标/行内代码/清除格式）、**标题 ▸**（1~6 级）、**插入 ▸**（链接/图片/表格/代码块/引用/分割线）、**表格 ▸**（完整行列操作）、**导出**（PDF / Word / HTML）、**在文件夹中显示**。

### 5.7 Emoji 与常用表情

工具栏「插入 → Emoji」打开选择器，顶部的「常用表情」可在 **设置 → 编辑器 → 常用表情** 自定义（最多 24 个）。

## 7. 图片、视频与音频

### 7.1 本地图片：`.assets` 规则

所有本地导入的图片（及音视频素材）都会**复制到文档同级的 `.assets` 目录**，并插入相对路径 `![alt](.assets/xxx.png)`，因此文档移动后图片依然可见。重名文件按「同名同大小复用，否则追加 `-1`、`-2`…」处理。**文档必须先保存一次**才能插入本地图片，否则会提示先保存。

### 7.2 三种插入路径

1. **对话框**：`Ctrl+Shift+I` / 工具栏 / 右键「插入图片」/ `/image`。弹窗三种模式：**本地图片**（复制到 .assets）、**链接**（直接填 URL）、**上传图床**（上传到已配置的图床服务）。
2. **拖拽**：图片文件拖到窗口，自动复制到 `.assets` 并插入。
3. **粘贴**：剪贴板里的截图/图片在桌面端优先复制到 `.assets`；未配置时降级为图床上传；浏览器环境嵌入 dataURL。

### 7.3 调整尺寸

- **尺寸语法**：`![替代文本](路径){width=320 height=200}`（只接受纯像素数字）。
- **双击预览中的图片**：打开「图片属性」弹窗，编辑路径、替代文本与尺寸。
- **右键预览中的图片**：小 (240px) / 中 (420px) / 大 (640px) / 原始尺寸、编辑属性…、复制路径、删除图片。尺寸只回写语法，不改动图片文件。

### 7.4 视频与音频

使用行内指令语法（独占一行），或工具栏「插入 → 视频/音频」：

```
@[video](demo.mp4)              本地/远程视频
@[audio](demo.mp3)              音频
@[youtube](https://youtu.be/xxxx)   YouTube（隐私增强域名）
@[video](https://www.bilibili.com/video/BVxxxx)   B 站（支持 BV/av 号）
@[video](https://vimeo.com/xxxx)    Vimeo
```

支持属性 `{title="演示" poster="cover.jpg"}`（poster 仅视频）。写图片语法 `![](demo.mp4)` 时音视频文件会自动提升为播放器。

### 7.5 图床服务

在 **设置 → 图床** 中选择启用的服务（默认「本地」）：

- **Cloudinary**：云名称、API Key、API 密钥、上传文件夹。
- **PicGo**：服务器地址（默认 `http://127.0.0.1:36677`）。
- **S3 / OSS**：支持阿里云 OSS、AWS S3、腾讯云 COS、华为 OBS、MinIO 及自定义端点，可配置桶、地域、密钥、路径与 HTTPS。

## 8. 预览渲染能力

### 8.1 数学公式（KaTeX）

四种写法均支持：行内 `$E=mc^2$`、块级 `$$…$$`、`\[…\]`、`\(…\)`。代码块中的 `$` 不会被误渲染，渲染失败回退显示原文。

### 8.2 Mermaid 图表

```` ```mermaid ```` 围栏，支持 Mermaid 全部图表类型（流程图、时序图、甘特图、状态图、类图等）。主题自动跟随明暗切换；语法错误时显示错误提示与源码；距视口 480px 内才渲染（懒加载）。

### 8.3 Markmap 思维导图

```` ```markmap ```` 围栏，内容直接用 Markdown 标题层级描述（`#` 中心主题、`##` 分支、`###` 要点），无需学习新语法。

- **插入**：`/markmap`、工具栏「图表」、功能菜单「插入思维导图」，插入后自动选中「中心主题」待改。
- **交互**：拖动平移、**Ctrl+滚轮缩放**、点击分支圆圈折叠/展开。
- **导出**：「适应视图」按钮复位视角；「导出 PNG」输出 2 倍分辨率图片（桌面端弹保存对话框）。

### 8.4 GitHub Actions 工作流查看器

- Markdown 中 ` ```yaml ` 围栏内容若「长得像」GitHub Actions 工作流，会自动渲染为可交互的 **job 依赖图（DAG）**（可在设置 → 工作流关闭）。
- 打开 `.github/workflows/*.yml` 文件时，预览区整体变为「依赖图 + 结构化编辑器」分屏，可编辑 job / step / `with` 字段后**写回编辑器**（保留注释与缩进，需再 Ctrl+S 保存文件）。
- 画布：Ctrl+滚轮缩放、拖动平移、点击 job 查看详情、诊断（GHA-* 错误/警告）可点击跳转源码行。
- 导出：「复制 Mermaid」「复制 SVG」「导出 SVG」。

### 8.5 其他渲染特性

- **任务列表**：`- [ ]` / `- [x]`；**在预览里点击 checkbox 会直接改写编辑器源码**。
- **表格列宽**：预览表格可拖动表头分隔线调整列宽（最小 60px），双击分隔线恢复自动宽度；列宽不写回 Markdown。
- **SVG 围栏**：` ```svg ` 校验净化后内联显示。
- **标题锚点**：`#标题` 内链可点击跳转；外链一律用系统浏览器打开。
- **双向定位**：点击预览段落跳到编辑器对应行；编辑光标处的对应预览块自动高亮；编辑器与预览基于标题锚点双向同步滚动。
- **单换行即换行**：预览采用 GitHub 风格的 breaks 行为。

> ⚠️ 注意区分：脚注 `[^1]` 与高亮 `==…==` 在**编辑器**中可插入、可原位编辑，但**预览面板当前不渲染**这两种语法（按普通文本显示）。

## 11. AI 智能助手

4. 点「**获取模型列表**」拉取可用模型并选择，或手动填写。
5. 可调**温度**（默认 0.7）与**写作风格**（正式/活泼/学术/创意/自定义提示词）。

点击侧栏 AI 图标打开面板，顶部可切换「**AI 对话**」与「**Agent（Beta）**」两个运行模式。

- **服务商/模型**：下拉列出当前服务商与已存密钥的服务商；偏好按工作区分别记忆。
- **关联文档**：自动把当前编辑文档作为对话上下文（气泡栏显示文档名，可点 × 取消）。
- **附件上传**：回形针按钮，支持多张图片（png/jpg/gif/webp/bmp/svg）与文本文件（txt/md/json/yaml/xml/csv/log）。
- **网络搜索**：工具栏搜索按钮（需先在设置 → 网络搜索启用）；开启后回答前先联网搜索，消息下方显示可展开的来源卡片，支持「导出来源」为 Markdown 脚注。

- **工作区上下文**：输入区上方的折叠条，可添加工作区文件作为检索来源，支持按标题选章节、敏感文件排除规则、「仅检索片段，不上传全文」（默认勾选），并显示本轮将发送的 Token 数与披露文案。

### 11.3 AI 指令面板（文本处理）

- **作用范围三档**（Tab 切换）：选中文本（无选区自动降级为光标所在段落）/ 当前段落 / 整个文档。
- 支持**自由指令**输入（带历史记录），也支持把自定义指令写成 Markdown 文件放进 `genies` 文件夹（面板内可一键打开该文件夹并重载）。
- AI 改写结果先经「**AI 修改建议**」差异审阅弹窗，确认后才写入文档；校对结果在专用面板中逐项查看并应用。

### 11.4 其他 AI 功能

- **AI 校对**：设置中「使用 AI 校对」开启时调用 AI 检测错别字、语法、标点；关闭后改用**内置 Markdown 静态校对**（检查未闭合代码围栏、反向链接、跳级标题、断开的锚点、表格列数不匹配等）。校对时会自动并联**本地链接检查**（M001/M002 缺失链接条目）；也可随时用 `Ctrl+Alt+V` 或菜单「功能 → 检查链接」单独运行，`F2` / `Shift+F2` 在结果间跳转。
- **伴写建议**：开启「自动伴写建议」（默认关）后，写作停顿超过设定延迟（默认 2000ms）会在光标处弹出 AI 续写建议。

## 12. 本地 Agent（Beta）

在同一 AI 面板中调用本机安装的 **Claude Code / Codex / OpenCode / Pi** CLI，让 Agent 直接在项目里执行任务。

### 12.1 启用步骤

1. 本机安装并登录任一 CLI（`claude` / `codex` / `opencode` / `pi`）——Zeditor 复用 CLI 自己的登录与默认模型，**不保存其账号凭据**。
2. 打开目标工作区目录。
3. **设置 → AI 助手 → 启用本地 Agent（Beta）**，选择默认 Agent，可配置可执行文件路径、模型覆盖、Agent/Profile、推理强度（自动/低/中/高/超高/最大）；点「检测本机 Agent」验证。Pi 无 Agent/Profile 概念，该项自动隐藏。
4. AI 面板顶部切到「Agent」标签。

### 12.2 审批机制

- **分级审批（默认）**：隔离区内的读取与文件编辑放行；Shell 命令、联网、MCP 工具需逐次审批；外部路径与 `git push` 硬性禁止。审批卡片提供四档：**拒绝 / 本次允许 / 本会话同类允许 / 本会话完全允许**。
- **完全访问**：切换时弹确认框；仅存于内存，重启或新建会话即恢复分级审批。
- **后端差异**：以上逐次审批依赖 CLI 自身的审批接口（Claude Code 的 PreToolUse Hook、Codex 的 app-server 请求、OpenCode 的 `permission.asked`）。**Pi 没有逐工具审批**，进入任务后会自行执行命令与编辑，`git push` 与外部路径的硬性禁止同样不适用；此时安全边界是隔离 worktree 与「应用前审阅」，Pi 扩展发出的 `select` / `confirm` 提示仍会以审批卡片呈现。

### 12.3 隔离变更审阅（Git worktree）

- 在 Git 仓库根目录中，每个新会话都会创建**独立的临时 Git worktree**，Agent 的修改不直接落在你的工作区。
- 回合结束后对比基线，产出「**待应用变更**」列表（每文件状态、增删行数），**勾选后按文件应用**；应用前检查文件是否被你手动改过，有冲突即中止。
- 非 Git 目录则授权后直接写入（界面会显示明确横幅提示）。
- 「丢弃会话」会删除 worktree 与本地事件历史。

### 12.4 会话与上下文

- 会话下拉可恢复当前工作区的历史会话（标题由 CLI 从首条提问生成）；切换后端会自动切换到该后端的会话。
- 自动引用当前文档；「@ 引用」引用选区或文档；「+」添加工作区文件作为附加上下文。
- 时间线折叠展示思考过程、终端输出、工具调用；助手消息可「插入编辑器」。

## 13. MCP 集成

Zeditor 内置 MCP 服务器，让 **Claude Desktop、Claude Code、Codex CLI、Gemini CLI** 等 AI 助手通过 MCP 协议直接读写你正在编辑的文档。

### 13.1 三步启用

1. **设置 → 集成**，开启「**启用 MCP 服务器**」（可同时开「启动时自动运行」）。
2. 在「AI 助手配置」区对所用客户端点「**安装**」，状态显示 ✓ 已安装（配置写入各客户端的配置文件：Claude Desktop 的 `claude_desktop_config.json`、Claude Code 的 `~/.claude.json`、Codex CLI 的 `config.toml`、Gemini CLI 的 `settings.json`）。
3. **完全退出并重启该 AI 助手**。

之后即可对助手说：「读取我当前在 Zeditor 里打开的文档，总结要点」「把选中的段落改得更简洁，然后保存」「列出我打开的标签页」。

### 13.2 可选开关

- **启动时自动运行**：Zeditor 打开即自动启动桥接。
- **自动批准编辑**：AI 修改直接落盘、不再弹出审阅——仅在完全信任该助手时开启。

### 13.3 提供的工具（11 个）

`session_get_state`、`workspace_new`、`workspace_open`、`workspace_save`、`workspace_save_as`、`workspace_close`、`workspace_switch_tab`、`document_read`（返回修订号）、`document_write`（支持乐观并发控制）、`selection_get`、`selection_set`。

### 13.4 安全边界

- 桥接**仅监听 127.0.0.1** 并使用**随机令牌认证**。
- 文件操作限定在已打开的工作区根与文档目录内，越界返回 `INVALID_PATH`。
- 默认不自动落盘：AI 修改以「AI 修改建议」差异审阅提交，你可接受 / 拒绝 / 撤销。
- 状态栏随时显示桥接状态；可随时停止桥接或关闭总开关。

## 14. 文档转换（AnyDoc）

将 **DOC/DOCX/DOCM、PPT/PPTX、XLS/XLSX、ODT/ODS/ODP、RTF、EPUB、CSV、PDF** 等文档一键转换为 Markdown，并在新标签页打开编辑。转换由按需下载的 AnyDoc 原生 Rust 模块完成，**始终在本机处理，不上传文件**。

### 14.1 触发方式

1. 资源管理器里**点击**可转换文档（有「点击即可转换为 Markdown」提示）；
2. 文件对话框打开时选择了可转换文件；
3. 菜单「文件 → **导入并转换文档…**」。

### 14.2 模块安装

首次转换时自动弹出安装引导：

- **在线安装（推荐）**：确认后从 GitHub Release 下载对应平台模块（约数 MB），自动完成 SHA-256 校验与健康检查后安装并转换。
- **离线导入**：在无网络环境，从 [converter-v1.3.0 Release](https://github.com/zhcx/zeditor/releases/tag/converter-v1.3.0) 下载对应平台 ZIP（Windows / macOS arm64 / macOS Intel / Linux x86_64），在 **设置 → 文档转换 → 导入离线包** 中导入。
- **卸载 / 重装**：设置 → 文档转换页提供模块状态（已安装版本 / 可更新 / 未安装 / 校验失败）、平台与空间占用，以及「在线安装 / 更新模块 / 重新安装 / 导入离线包 / 卸载模块」按钮。
- 开发调试可通过环境变量 `ANYDOC_CONVERTER_PATH` 直接指向本地构建的转换器可执行文件。

### 14.3 范围与安全

- PDF 仅支持**文本型**文档，扫描型 PDF 需 OCR（暂不支持）；图片、音频、MSG、Notebook 不在转换范围内。
- 发布清单使用 Ed25519 签名验证，模块可执行文件强制 SHA-256 校验。

## 15. 导出功能

入口统一在菜单「**文件 → 导出**」子菜单。

### 15.1 导出模板（各导出方式共用）

9 个预设：**公众号文章、学术论文、公文排版、技术文档、演示长图、小红书长图、A4 打印、GitHub README、自定义 CSS**。可调项：字体、行距、水印、包含目录（H1–H3）、包含封面、页眉页脚、标题自动编号、自定义 CSS。选择会记住。

### 15.2 各导出方式

- **导出为 HTML**：直接执行，应用当前模板，弹系统保存对话框。
- **导出为 PDF**：模板区 + 页面设置（A4/A3/Letter/Legal、纵/横向、页边距 5–50mm 默认 20、页眉页脚）；导出过程有 5 步进度指示（初始化→加载→渲染→生成→完成）。
- **导出为 Word**：保存为 `.doc`。
- **导出为图片**：PNG 长图，5 种画布比例——1:1（卡片）、4:3（演示/平板）、16:9（宽屏封面）、9:16（手机长图）、A4（打印），2 倍分辨率渲染，带实时预览，跟随当前主题底色。
- **导出公众号排版 HTML**：6 个原创主题（翡翠指南 / 朱砂论述 / 石墨刊读 / 留白随笔 / 琥珀便签 / 橄榄书页），全内联样式，自动加封面卡；可「复制富文本」直接粘贴进公众号编辑器，或「保存 HTML」。

## 16. 云备份（WebDAV / S3）

本地保存成功后自动把文档备份到自建的 WebDAV 服务器或 S3 兼容对象存储（AWS S3、阿里云 OSS、腾讯云 COS、MinIO、Cloudflare R2 等）。在 **设置 → 云同步** 中分别配置，**两者可同时启用**，各自独立队列与状态。

### 16.1 配置

- **WebDAV**：开启「启用 WebDAV 自动备份」，填服务器地址（如 `https://example.com/dav`）、用户名、密码/应用密码、远端根目录（默认 `/Zeditor`），点「测试连接」验证。凭据仅保存在本地设备。
- **S3 云同步**：填服务端点、存储桶、地域、Access Key / Secret Key、路径风格（自建 MinIO 等启用 Path-Style）、远端根目录；根目录只在桶内路径前添加一次，`/Zeditor` 会生成 `Zeditor/工作区/文档.md`。

### 16.2 行为

- **版本策略**：保留最新副本 + 最近 **20 个不同内容版本**（按 SHA-256 去重）。
- **失败安全**：云端备份失败不影响本地保存；失败任务持久化，应用重启后自动恢复；状态栏实时显示同步状态，可点击重试。
- **历史浏览**：「浏览全部备份」打开历史对话框，历史版本按「另存为」下载，下载前校验哈希。

## 17. 设置面板详解

设置面板为左侧分类导航 + 右侧内容区，修改先暂存，点底部「**保存**」统一写入。共 11 个分类：

### 17.1 文档转换
转换模块状态、平台与空间占用、支持格式列表；「在线安装 / 导入离线包 / 卸载模块」按钮；高级项为开发调试用的 `ANYDOC_CONVERTER_PATH`。

### 17.2 外观
界面显示语言（简体中文 / 繁體中文 / 日本語 / 한국어 / English，更改即时生效）、主题（12 套并可跟随系统）、界面字体与内容字体（可「读取本机字体」）、界面字号（11–20 px，默认 13 px）、字间距（0–5 px，步进 0.1，默认 **0.6 px**）、正文字号与行高（1.0–3.0）。界面字号和正文字号独立调整，字号与间距滑块都能实时预览；点击「取消」恢复打开设置前的值，点击「保存」会在下次启动时恢复偏好。

### 17.3 编辑器
自动保存间隔（默认 30000ms）、输入法引擎（EditContext 原生 / textarea 回退）、拼写检查（默认关）、自动补全、**自动配对与 Tab 跳出**（默认开）、固定显示编辑快捷栏（默认关，关时仅选中文字浮现）、**启用内联弹窗**（默认开）、常用表情（最多 24 个）。macOS 在菜单、弹窗与提示中使用 ⌘（Command）、⇧（Shift）、⌥（Option）标识快捷键；其他平台显示 Ctrl / Shift / Alt。

### 17.4 图床
见[第 7.5 节](#75-图床服务)。

### 17.5 导出
PDF 页边距（默认 20mm）、HTML 模板（默认 / 极简 / 学术）。

### 17.6 AI 助手

### 17.7 资源管理器

### 17.8 工作流

## 18. 自动更新

- 入口：应用菜单（左上角 Zeditor 菜单）→「**检查更新**」。
- 自动检测 GitHub Release 最新版本（Atom feed 优先，失败回退 GitHub API），弹窗展示版本对比与更新说明。
- 「**下载并安装**」实时显示下载进度；Windows 下完成后自动启动安装程序（安装前会退出应用，请先保存文档）。
- 检查失败时可「前往 GitHub Release」手动下载。

## 20. 常见问题与故障排除

| 问题 | 原因 | 解决方法 |
| --- | --- | --- |
| 提示「请先保存文档」才能插图 | 本地图片需复制到文档同级 `.assets` | 先 Ctrl+S 保存一次再插入 |
| 粘贴图片提示未配置图床 | 桌面端写入 .assets 失败或环境不支持 | 在设置 → 图床中启用并配置服务 |
| 提示 `converter_module_missing` | 未安装 AnyDoc 模块 | 设置 → 文档转换：在线安装或导入离线 ZIP |
| 下载转换模块失败 | 网络问题 | 检查网络或使用离线包导入 |
| 转换结果为空 | 源文件是扫描件/图片型 PDF | 确认源文件含可提取文本（扫描型暂不支持） |
| `[^1]` 脚注、`==高亮==` 预览不生效 | 预览暂未启用这两种渲染插件 | 属预期行为；编辑器内仍可插入与原位编辑 |
| 双击标签页把文档关了 | 双击标签 = 关闭（非重命名） | 未保存会弹确认框，不会丢内容 |
| Agent 面板显示「尚未启用」 | 未开启本地 Agent | 设置 → AI 助手 → 启用本地 Agent（Beta）并检测 CLI |
| Agent 显示 CLI「不可用/不兼容」 | CLI 版本过旧 | 升级对应 CLI 到支持结构化流式输出的版本 |
| MCP 助手连不上 | 客户端未重启或配置路径不匹配 | 完全退出并重启该 AI 助手；设置 → 集成中点「安装/修复」 |
| 沉浸模式 / 演示模式退不出 | — | 按 Esc；演示模式也可点左上角「✕ 退出」 |
| SmartScreen 拦截安装包 | Windows 包尚未代码签名 | 「更多信息 → 仍要运行」；发布包强制哈希校验 |
